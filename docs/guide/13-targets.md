# 13. What the compiler generates

`wolf build` writes a project of the target language to `out/<target>/`. The generated code is
meant to be read: it is formatted the way `prettier`, `gofmt` and `rustfmt` would format it, keeps
the doc comments, and passes `tsc --strict`, `go vet` and `cargo clippy`. This chapter shows what a
small program becomes; [chapter 8 of the specification](../spec/08-targets.md) has every rule.

```wolf
module main

types {
    enum Shape {
        Circle(Float)
        Rect { w: Float, h: Float }
    }
}

main {
    let shapes = [Shape.Circle(1.0), Shape.Rect { w: 2.0, h: 3.0 }]
    print(total(shapes).to_string())
}

functions {
    /// The area of a shape.
    fn area(s: Shape) -> Float {
        match s {
            Shape.Circle(r) => 3.0 * r * r
            Shape.Rect { w, h } => w * h
        }
    }

    fn total(shapes: List<Shape>) -> Float {
        var sum = 0.0
        for s in shapes {
            sum += area(s)
        }
        sum
    }
}

// file: wolfpack.toml
[package]
name = "shapes"
version = "0.1.0"
kind = "cli"
```

```output
9.0
```

## TypeScript

```ts generated src/main.ts
// Generated by wolf from src/main.wolf. Do not edit.

import * as $rt from "./wolf_rt.js";

export type Shape = ShapeCircle | ShapeRect;

export class ShapeCircle {
  readonly kind: "Circle" = "Circle";
  _0: number;

  constructor(_0: number) {
    this._0 = _0;
  }
}

export class ShapeRect {
  readonly kind: "Rect" = "Rect";
  w: number;
  h: number;

  constructor(w: number, h: number) {
    this.w = w;
    this.h = h;
  }
}

function main(): void {
  const shapes: Shape[] = [new ShapeCircle(1.0), new ShapeRect(2.0, 3.0)];
  $rt.print($rt.floatToString(total(shapes)));
}

/** The area of a shape. */
function area(s: Shape): number {
  if (s.kind === "Circle") {
    const r = s._0;
    return 3.0 * r * r;
  } else {
    const w = s.w;
    const h = s.h;
    return w * h;
  }
}

function total(shapes: Shape[]): number {
  let sum: number = 0.0;
  for (const s of shapes) {
    sum = sum + area(s);
  }
  return sum;
}

$rt.runMain(main);
```

- An enum with data becomes one class per variant with a `kind` field, and a union type; `match`
  becomes a chain of `if` on `kind`.
- `Int` is a `bigint`, so that it has 64 bits; `Float` is a `number`.
- Runtime support, such as the canonical float format, comes from a generated `wolf_rt.ts` that
  holds only the pieces the program uses. `runMain` turns a panic into the same message and exit
  code as on the other targets.

## Go

```go generated main.go
// Generated by wolf from src/main.wolf. Do not edit.

package main

import (
	"fmt"
	"shapes/wolfrt"
)

type shape interface {
	isShape()
}

type shapeCircle struct {
	F0 float64
}

func (*shapeCircle) isShape() {}

type shapeRect struct {
	W float64
	H float64
}

func (*shapeRect) isShape() {}

func main_() {
	shapes := []shape{&shapeCircle{F0: 1.0}, &shapeRect{W: 2.0, H: 3.0}}
	fmt.Println(wolfrt.FloatString(total(shapes)))
}

// The area of a shape.
func area(s shape) float64 {
	switch v := s.(type) {
	case *shapeCircle:
		r := v.F0
		return 3.0 * r * r
	case *shapeRect:
		w := v.W
		h := v.H
		return w * h
	default:
		panic("unreachable")
	}
}

func total(shapes []shape) float64 {
	sum := 0.0
	for _, s := range shapes {
		sum += area(s)
	}
	return sum
}

func main() {
	wolfrt.RunMain(main_)
}
```

- Each module is a Go package; names are adjusted to Go's rules, exported when `pub`.
- An enum with data is a sealed interface with a struct per variant, and `match` is a type switch.
- `Option` and `Result` become the idiomatic forms where they can: `(T, error)` results and `?` as
  `if err != nil { return ..., err }`.

## Rust

```rust generated src/main.rs
// Generated by wolf from src/main.wolf. Do not edit.

#![allow(arithmetic_overflow, unconditional_panic, unknown_lints)]
#![allow(clippy::type_complexity, clippy::single_match, clippy::manual_contains)]

mod wolf_rt;

#[derive(Clone, PartialEq)]
pub enum Shape {
    Circle(f64),
    Rect { w: f64, h: f64 },
}

fn main_() {
    let shapes: Vec<Shape> = vec![Shape::Circle(1.0), Shape::Rect { w: 2.0, h: 3.0 }];
    println!("{}", wolf_rt::float_to_string(total(&shapes)));
}

/// The area of a shape.
pub fn area(s: &Shape) -> f64 {
    match s {
        Shape::Circle(r) => 3.0 * *r * *r,
        Shape::Rect { w, h } => *w * *h,
    }
}

pub fn total(shapes: &[Shape]) -> f64 {
    let mut sum: f64 = 0.0;
    for s in shapes {
        sum += area(s);
    }
    sum
}

fn main() {
    wolf_rt::run_main(main_);
}
```

- The parameter modes become borrows: a read parameter is `&T` (or `&str`, `&[T]`), a `mut`
  parameter `&mut T`, and an `own` parameter takes `T` by value.
- `Option`, `Result` and `?` are Rust's own; recursive types are boxed where needed.
- Integer overflow panics through `overflow-checks = true` in `Cargo.toml`.

## Building the output yourself

The generated projects need no `wolf` to build: `npm install` and `tsc` for TypeScript, `go build`
for Go, `cargo build` for Rust. Every generated file starts with a comment naming its source and
saying that it should not be edited; change the `.wolf` source and build again instead.

## Running without the tools: the VM

`wolf run --vm` and `wolf test --vm` do not generate a project at all: `wolf` compiles the program
into a bytecode of its own and runs it in its virtual machine. Nothing needs to be installed, and
the program prints exactly what it prints on the three targets, with the same panic messages and
exit codes.

```text
$ wolf run --vm
9.0
$ wolf test --vm
test result: ok. 0 passed; 0 failed
```

The VM runs only wolfpack code and std. A program that calls code of the targets, through an
`extern` section or a native module, cannot run in it: `wolf run --vm` reports E0807 and names the
module and the chain of imports that reaches it. [Chapter 10 of the
specification](../spec/10-vm.md) has the rules.
