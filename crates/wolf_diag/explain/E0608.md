# E0608: type less visible than the declaration using it

A public declaration mentions a type that its users cannot name: a private type in a public
function, a private interface that a public interface extends, or, in a library, a type that the API
uses but `src/lib.wolf` does not re-export. Make the type `pub` (and re-export it in a library), or
make the declaration private.

Wrong:

```wolf wrong
module main

imports {
    shapes.{make}
}

main {
    let _ = make()
}

// file: src/shapes.wolf
module shapes

types {
    struct Secret {
        x: Int
    }
}

functions {
    pub fn make() -> Secret {
        Secret { x: 1 }
    }
}
```

Fixed:

```wolf fixed
module main

imports {
    shapes.{make}
}

main {
    let _ = make()
}

// file: src/shapes.wolf
module shapes

types {
    pub struct Secret {
        x: Int
    }
}

functions {
    pub fn make() -> Secret {
        Secret { x: 1 }
    }
}
```
