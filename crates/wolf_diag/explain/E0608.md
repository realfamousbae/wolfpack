# E0608: type less visible than the declaration using it

A public declaration mentions a type that is less visible than itself, for example a `pub fn`
returning a private struct. Users of the function could not name its type. Make the type `pub`, or
the function private.

Wrong:

```text
// src/shapes.wolf
types {
    struct Secret {
        x: Int
    }
}

functions {
    pub fn make() -> Secret { Secret { x: 1 } }
}
```

Fixed:

```text
types {
    pub struct Secret {
        pub x: Int
    }
}
```
