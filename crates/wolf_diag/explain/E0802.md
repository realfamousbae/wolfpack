# E0802: target tool rejected the generated code

The tool of the target, such as `tsc`, `go vet` or `cargo`, rejected the code that `wolf` generated.
A program that passes `wolf check` must always build, so this is a bug in `wolf`. The note shows the
message of the tool; please report it with the input that caused it.

Wrong:

```text
$ wolf run --target ts
error[E0802]: TypeScript rejected the generated code
  = note: main.ts(1,1): error TS2322: ...
```

Fixed:

There is nothing to fix in the program. Report the bug with the program and the note.
