# E0616: import of an entry module or of the module itself

A module imports itself or the entry module (`main` or `lib`). The entry module is the root of the
program; move what other modules need out of it into a module of its own.

Wrong:

```wolf
module main

imports {
    main.{helper}
}

functions {
    fn helper() {
        print("x")
    }

    fn main() {
        helper()
    }
}
```

Fixed:

```wolf
module main

functions {
    fn helper() {
        print("x")
    }

    fn main() {
        helper()
    }
}
```
