# E0616: import of an entry module or of the module itself

A module imports itself, or imports an entry module (`main`, `lib`, a test or an example). Entry
modules are the roots of the project and nothing depends on them. Move the shared declarations into
a module of their own and import that.

Wrong:

```wolf wrong
module main

imports {
    util.{run}
}

functions {
    pub fn helper() -> String {
        "x"
    }

    fn main() {
        print(run())
    }
}

// file: src/util.wolf
module util

imports {
    main.{helper}
}

functions {
    pub fn run() -> String {
        helper()
    }
}
```

Fixed:

```wolf fixed
module main

imports {
    util.{run}
}

functions {
    fn main() {
        print(run())
    }
}

// file: src/util.wolf
module util

functions {
    fn helper() -> String {
        "x"
    }

    pub fn run() -> String {
        helper()
    }
}
```
