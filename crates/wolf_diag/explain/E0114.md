# E0114: unbalanced brace in an interpolated string

In an interpolated string `f"..."`, a `{` starts an expression that ends at its matching `}` on
the same line. A `{` that is never closed, or a `}` that closes nothing, is an error. To put a
brace character into the text, double it: `{{` and `}}`.

Wrong:

```wolf wrong
module main

main {
    print(f"{{total}}: {2 * 3")
}
```

Fixed:

```wolf fixed
module main

main {
    print(f"{{total}}: {2 * 3}")
}
```
