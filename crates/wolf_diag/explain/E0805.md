# E0805: wolf could not be updated

`wolf self update` could not download, check or install a release. The message says why: the
network may be down, the download may be damaged (its SHA-256 sum is checked against
`SHA256SUMS.txt` of the release), or the directory of `wolf` may not be writable. The running
`wolf` is replaced only after the new one has been checked and has started once, so a failed
update leaves the old `wolf` as it was. A `wolf` installed by Cargo or Homebrew is updated with
that tool instead.

Wrong:

```text
$ wolf self update
downloading wolf 0.3.0
error[E0805]: cannot write into /usr/local/bin: Permission denied (os error 13)
  = help: install the new release with the installer instead: https://github.com/realfamousbae/wolfpack#install
```

Fixed:

```text
$ wolf self update
downloading wolf 0.3.0
installed wolf 0.3.0 into /home/ann/.local/bin
```
