# E0404: bound not satisfied

A type argument does not implement an interface that the generic function or type requires. For
example `list.sort` needs `Comparable`, which `Float` is not (NaN has no order); sort floats with
`list.sort_by` and a comparison.

Wrong:

```wolf
module main

imports {
    std.list
}

functions {
    fn main() {
        var xs = [2.5, 1.5]
        list.sort(mut xs)
        print(xs[0].to_string())
    }
}
```

Fixed:

```wolf
module main

imports {
    std.list
}

functions {
    fn main() {
        var xs = [2, 1]
        list.sort(mut xs)
        print(xs[0].to_string())
    }
}
```
