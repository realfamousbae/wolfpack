# E0404: bound not satisfied

A type argument does not implement an interface that the type parameter requires, as in
`sort<T: Comparable>`. Implement the interface for the type in an `impl` block, or use another
function: `Float` is not `Comparable` because of NaN, so floats are sorted with `list.sort_by` and a
comparison function.

Wrong:

```wolf wrong
module main

imports {
    std.list
}

types {
    struct Point {
        x: Int
    }
}

functions {
    fn main() {
        var points = [Point { x: 2 }, Point { x: 1 }]
        list.sort(mut points)
        print(points[0].x.to_string())
    }
}
```

Fixed:

```wolf fixed
module main

imports {
    std.list
}

types {
    struct Point {
        x: Int
    }
}

impl {
    Point: Comparable {
        fn compare(self, other: Self) -> Ordering {
            self.x.compare(other.x)
        }
    }
}

functions {
    fn main() {
        var points = [Point { x: 2 }, Point { x: 1 }]
        list.sort(mut points)
        print(points[0].x.to_string())
    }
}
```
