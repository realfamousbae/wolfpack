# E0702: type not allowed at the extern boundary

Only `Int`, `Float`, `Bool`, `String`, `Void`, `List`, `Option`, `Result<_, Error>` and extern
types cross the extern boundary. Maps, structs, enums and interfaces do not; pass their parts
instead.

Wrong:

```wolf
module main

extern {
    ts {
        fn keys(m: Map<String, Int>) -> List<String> from "Object.keys"
    }
}

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

extern {
    ts {
        fn upper(s: String) -> String from "String.prototype.toUpperCase"
    }
}

functions {
    fn main() {
        print(upper("hi"))
    }
}
```
