# E0702: type not allowed at the extern boundary

Only types that every target can pass to its own code cross the extern boundary: `Int`, `Float`,
`Bool`, `String`, `Void`, `List` and `Option` of these, `Result<_, Error>`, and extern types. Maps,
user structs and enums, and results with other error types are converted by Wolfpack code around the
extern function.

Wrong:

```wolf wrong
module main

extern {
    ts {
        fn keys(m: Map<String, Int>) -> List<String> from "Object.keys"
    }
}

functions {
    fn main() {
        print(keys(["a": 1]).len().to_string())
    }
}
```

Fixed:

```wolf fixed
module main

extern {
    ts {
        fn join(items: List<String>, sep: String) -> String from "lib#join"
    }
}

functions {
    fn main() {
        print(join(["a", "b"], ","))
    }
}
```
