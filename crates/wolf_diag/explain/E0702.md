# E0702: type not allowed at the extern boundary

Only types that every target can pass to its own code cross the extern boundary: `Int`, `Float`,
`Bool`, `String`, `Void`, `List`, `Option` and `Map` of these (map keys only `Int`, `String` or
`Bool`), `Result<_, Error>`, and extern types. A map is copied at the boundary, so its values may
not hold extern types, which cannot be copied. User structs and enums, maps with other keys, and
results with other error types are converted by wolfpack code around the extern function.

Wrong:

```wolf wrong
module main

extern {
    ts {
        fn size(m: Map<Color, Int>) -> Int from "lib#size"
    }
}

types {
    enum Color {
        Red
    }
}

main {
    print(size([Color.Red: 1]).to_string())
}
```

Fixed:

```wolf fixed
module main

extern {
    ts {
        fn join(items: List<String>, sep: String) -> String from "Array.prototype.join"
    }
}

main {
    print(join(["a", "b"], ","))
}
```
