# E0003: internal compiler error

The compiler itself failed. This is never the fault of the program: every invalid program must get a
diagnostic with its own code. Please report the bug together with the smallest input that shows it.
Until it is fixed, writing the construct named in the note in another way usually avoids the
failure.

Wrong:

```text
$ wolf check
error[E0003]: internal compiler error
  = note: the compiler failed: ...
  = help: this is a bug in wolf; please report it with the input that caused it
```

Fixed:

There is nothing to fix in the program. Report the bug with the input that caused it.
