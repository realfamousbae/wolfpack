# E0711: record binding does not name a struct of the module

`struct Name from "path"` in an extern block binds a struct of the module to a struct type of the
target, so that it crosses the boundary by value, field by field. The name must be a struct declared
in the `types` section of the same module, and the struct may not be generic.

Wrong:

```wolf wrong
module main

extern {
    ts {
        struct Point from "native:geo#Point"
    }
}

main {
    print("hi")
}

// file: native/ts/geo.ts
export interface Point {
  x: number;
  y: number;
}
```

Fixed:

```wolf fixed
module main

extern {
    ts {
        struct Point from "native:geo#Point"
    }
}

types {
    struct Point {
        x: Float
        y: Float
    }
}

main {
    let p = Point { x: 1.0, y: 2.0 }
    print(f"{p.x}")
}

// file: native/ts/geo.ts
export interface Point {
  x: number;
  y: number;
}
```
