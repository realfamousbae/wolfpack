# E0310: closure with a result type but without a block body

A closure body may be a single expression, as in `|x| x + 1`. When the closure states its result
type with `->`, the body must be a block, so that the type and the body are clearly apart.

Wrong:

```wolf wrong
module main

main {
    let inc = |x: Int| -> Int x + 1
    print(inc(1).to_string())
}
```

Fixed:

```wolf fixed
module main

main {
    let inc = |x: Int| -> Int { x + 1 }
    print(inc(1).to_string())
}
```
