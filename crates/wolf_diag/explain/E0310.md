# E0310: closure with a result type but without a block body

A closure with a written result type has a block body: `|x| -> Int { x + 1 }`. Without a result
type the body may be any expression.

Wrong:

```wolf
module main

functions {
    fn main() {
        let inc = |x: Int| -> Int x + 1
        print(inc(1).to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let inc = |x: Int| -> Int { x + 1 }
        print(inc(1).to_string())
    }
}
```
