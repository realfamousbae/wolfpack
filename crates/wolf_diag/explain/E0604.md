# E0604: import cycle

Modules import each other in a cycle. Move what both need into a third module that both import.

Wrong:

```text
// src/a.wolf
module a

imports {
    b
}

// src/b.wolf
module b

imports {
    a
}
```

Fixed:

```text
// src/a.wolf imports `common`, src/b.wolf imports `common`,
// and src/common.wolf holds what both need.
```
