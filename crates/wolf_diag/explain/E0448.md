# E0448: an interface implementation for one instantiation

The head of an inherent block may give a type argument, so that its methods exist for one
instantiation of a generic type only: `Stack<Int> { fn sum(self) -> Int { ... } }`. An interface
implementation cannot: `Stack<Int>: Display` is an error. Go cannot give one instantiation of a
generic type a method that the others lack, so the type could not meet a Go interface. Implement
the interface for every instantiation, with a parameter in the head (and a bound on it if the
methods need one), or put the methods into an inherent block for the instantiation.

Wrong:

```wolf wrong
module main

types {
    struct Stack<T> {
        items: List<T>
    }
}

impl {
    Stack<Int>: Display {
        fn to_string(self) -> String {
            f"a stack of {self.items.len()} numbers"
        }
    }
}

main {
    print(Stack { items: [1, 2] }.to_string())
}
```

Fixed:

```wolf fixed
module main

types {
    struct Stack<T> {
        items: List<T>
    }
}

impl {
    Stack<T>: Display {
        fn to_string(self) -> String {
            f"a stack of {self.items.len()} items"
        }
    }

    Stack<Int> {
        fn sum(self) -> Int {
            var total = 0
            for x in self.items {
                total += x
            }
            total
        }
    }
}

main {
    let s = Stack { items: [1, 2] }
    print(f"{s.to_string()}, sum {s.sum()}")
}
```
