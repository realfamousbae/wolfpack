# E0301: unexpected token

The parser expected one kind of token and found another, for example a missing name after `let`, or
`pub` where no visibility is allowed (`impl` blocks, methods of an interface implementation and the
`tests` section have none). The message says what was expected.

Wrong:

```wolf wrong
module main

functions {
    fn main() {
        let = 5
        print("after")
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn main() {
        let count = 5
        print(count.to_string())
    }
}
```
