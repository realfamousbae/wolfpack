# E0301: unexpected token

The parser found a token that cannot come at this place. The message says what was expected. A
common cause is a keyword used as a name, such as `type` or `match`.

Wrong:

```wolf
module main

functions {
    fn main() {
        let type = 1
        print(type.to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let kind = 1
        print(kind.to_string())
    }
}
```
