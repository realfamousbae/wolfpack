# E0618: unused local variable

A local variable is never used. Remove it, or write `let _ = ...` to compute the value without
keeping it.

Wrong:

```wolf
module main

functions {
    fn main() {
        let unused = 1
        print("hi")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print("hi")
    }
}
```
