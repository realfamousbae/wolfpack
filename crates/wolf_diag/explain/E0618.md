# E0618: unused local variable

A local variable, or a name bound by a pattern, is never read. Remove it, write `_` instead of the
name in a pattern, or write `let _ = ...` to compute a value without keeping it.

Wrong:

```wolf wrong
module main

main {
    let count = 1
    print("done")
}
```

Fixed:

```wolf fixed
module main

main {
    let _ = 1
    print("done")
}
```
