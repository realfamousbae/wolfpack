# E0507: missing or unexpected `mut` or `own` marker

A call must say how each argument is passed when the parameter is `mut` or `own`: write `mut x` or
`own x` at the call. A marker for a read parameter is an error too. The markers make changes and
moves visible where they happen.

Wrong:

```wolf
module main

functions {
    fn bump(mut n: Int) {
        n += 1
    }

    fn main() {
        var n = 1
        bump(n)
        print(n.to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn bump(mut n: Int) {
        n += 1
    }

    fn main() {
        var n = 1
        bump(mut n)
        print(n.to_string())
    }
}
```
