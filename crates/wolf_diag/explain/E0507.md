# E0507: missing or unexpected `mut` or `own` marker

The mode of a parameter is repeated at the call site, so that every change or move is visible where
it happens: a `mut` parameter takes `mut x`, an `own` parameter takes `own x`, and a plain parameter
takes no marker. A fresh value, such as a literal, a call result or `x.copy()`, is passed to an
`own` parameter without a marker.

Wrong:

```wolf wrong
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

main {
    var u = User { name: "ann", tags: ["a"] }
    change(u)
    print(u.name)
}

functions {
    fn change(mut u: User) {
        u.name = "changed"
    }
}
```

Fixed:

```wolf fixed
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

main {
    var u = User { name: "ann", tags: ["a"] }
    change(mut u)
    print(u.name)
}

functions {
    fn change(mut u: User) {
        u.name = "changed"
    }
}
```
