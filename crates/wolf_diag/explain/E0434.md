# E0434: update syntax on an enum variant

The update syntax `..base` builds a struct from another value of the same struct. A variant of an
enum cannot be built that way, because the base may be another variant. Write every field of the
variant.

Wrong:

```wolf wrong
module main

types {
    enum Shape {
        Rect { w: Int, h: Int }
        Dot
    }
}

main {
    let a = Shape.Rect { w: 1, h: 2 }
    let b = Shape.Rect { w: 3, ..a }
    match b {
        Shape.Rect { w, .. } => print(w.to_string())
        Shape.Dot => print("dot")
    }
}
```

Fixed:

```wolf fixed
module main

types {
    enum Shape {
        Rect { w: Int, h: Int }
        Dot
    }
}

main {
    let b = Shape.Rect { w: 3, h: 2 }
    match b {
        Shape.Rect { w, .. } => print(w.to_string())
        Shape.Dot => print("dot")
    }
}
```
