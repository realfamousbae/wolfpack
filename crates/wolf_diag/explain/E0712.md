# E0712: native module re-exported

A native module (`native.<path>`) cannot be re-exported with a `pub` import: its names are read
from target code, and the API of a library is written in wolfpack. Import it without `pub`, and
write a function of the library that calls the native one.

Wrong:

```wolf wrong
// file: src/lib.wolf
module lib

imports {
    pub native.slug
}

// file: native/rust/slug.rs
pub fn slugify(s: &str) -> String {
    s.to_lowercase()
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "lib"

[targets]
default = "rust"
```

Fixed:

```wolf fixed
// file: src/lib.wolf
module lib

imports {
    native.slug
}

functions {
    /// The slug of a title.
    pub fn slug_of(title: String) -> String {
        slug.slugify(title)
    }
}

// file: native/rust/slug.rs
pub fn slugify(s: &str) -> String {
    s.to_lowercase()
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "lib"

[targets]
default = "rust"
```
