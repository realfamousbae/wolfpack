# E0801: target tool not installed

`wolf run` and `wolf test` build the generated project with the tools of the target, and `wolf`
cannot find the tool on `PATH`: `node` and `tsc` for TypeScript, `go` for Go, `cargo` for Rust.
Install the tool (Node.js 22, Go 1.24, Rust 1.85 or later), or use `wolf build`, which only writes
the generated project.

Wrong:

```text
$ wolf run --target go
error[E0801]: `go` is not installed
```

Fixed:

```text
$ brew install go
$ wolf run --target go
```
