# E0801: target tool not installed

`wolf run`, `wolf test` and `wolf build` of some projects need the tools of the target: `node` and
`tsc` for TypeScript, `go` for Go, `cargo` for Rust. The tool was not found on `PATH`. The hint
says how to install it. `wolf build` alone needs no tools.

Wrong:

```text
$ wolf run --target go
error[E0801]: `go` is not installed
```

Fixed:

```text
$ brew install go        # or from https://go.dev/dl
$ wolf run --target go
```
