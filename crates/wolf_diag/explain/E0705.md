# E0705: malformed extern path

The path after `from` does not have the form of its target: Go `import/path.Name` or a method
expression `(*bytes.Buffer).WriteString`; TypeScript `module#export` or a global path such as
`Math.max`; Rust a path such as `std::cmp::max`.

Wrong:

```wolf
module main

extern {
    go {
        fn upper(s: String) -> String from "ToUpper"
    }
}

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

extern {
    go {
        fn upper(s: String) -> String from "strings.ToUpper"
    }
}

functions {
    fn main() {
        print("hi")
    }
}
```
