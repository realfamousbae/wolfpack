# E0705: malformed extern path

The path after `from` does not have the form of the target. In TypeScript it is `module#export`,
`module#default` or a global path such as `Math.max`. In Go it is `import/path.Name`, a method
expression such as `(*bytes.Buffer).WriteString`, or for a type `*import/path.Name`. In Rust it is a
path with `::`, such as `std::cmp::max`.

Wrong:

```wolf wrong
module main

extern {
    go {
        fn upper(s: String) -> String from "ToUpper"
    }
}

functions {
    fn main() {
        print(upper("a"))
    }
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "cli"

[targets]
default = "go"
```

Fixed:

```wolf fixed
module main

extern {
    go {
        fn upper(s: String) -> String from "strings.ToUpper"
    }
}

functions {
    fn main() {
        print(upper("a"))
    }
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "cli"

[targets]
default = "go"
```
