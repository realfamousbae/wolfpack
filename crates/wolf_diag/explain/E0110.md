# E0110: carriage return without line feed

A carriage return (`\r`, U+000D) in the source is not followed by a line feed. Lines must end with
`LF` or `CRLF`; a lone `CR` is the line ending of very old Mac editors. Save the file with LF or
CRLF line endings; `wolf fmt` always writes LF.

Wrong:

Lines separated by a lone CR:

```text
module main<CR><CR>config {<CR>    limit: Int = 1<CR>}<CR>
```

Fixed:

The same lines separated by LF:

```text
module main<LF><LF>config {<LF>    limit: Int = 1<LF>}<LF>
```
