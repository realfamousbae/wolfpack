# E0612: invalid project layout

The files of the project do not follow the layout: a program has `src/main.wolf`, a library
`src/lib.wolf`, `src/` holds only `.wolf` files and directories, and every file and directory name
is a valid `snake_case` module name.

Wrong:

```wolf wrong
module main

main {
    print("hi")
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "lib"
```

Fixed:

```wolf fixed
module main

main {
    print("hi")
}
```
