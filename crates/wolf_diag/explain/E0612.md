# E0612: invalid project layout

The project layout is not valid: `src/main.wolf` is missing in a `cli` project (or
`src/lib.wolf` in a `lib`), or a file or directory name cannot be a module name.

Wrong:

```text
my-app/
  wolfpack.toml        # kind = "cli"
  src/
    app.wolf
```

Fixed:

```text
my-app/
  wolfpack.toml
  src/
    main.wolf
```
