# E0505: change of an immutable binding

A binding declared with `let` cannot be changed: not assigned, not changed through a field, and not
passed as `mut`. Declare it with `var` if it is meant to change. Loop variables of `for x in list`
cannot be changed either; use `for x in mut list` to change the elements.

Wrong:

```wolf wrong
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn main() {
        let u = User { name: "ann", tags: ["a"] }
        u.name = "bob"
        print(u.name)
    }
}
```

Fixed:

```wolf fixed
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn main() {
        var u = User { name: "ann", tags: ["a"] }
        u.name = "bob"
        print(u.name)
    }
}
```
