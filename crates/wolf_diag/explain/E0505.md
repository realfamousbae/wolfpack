# E0505: change of an immutable binding

A `let` binding or a read parameter is changed. Declare the variable with `var`, or take the
parameter as `mut`.

Wrong:

```wolf
module main

functions {
    fn main() {
        let n = 1
        n += 1
        print(n.to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        var n = 1
        n += 1
        print(n.to_string())
    }
}
```
