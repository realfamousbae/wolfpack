# E0210: second inherent `impl` block for a type

All methods of a type that do not implement an interface go into one inherent block `Type { }` of
the `impl` section. A second block for the same type is not allowed; merge the methods into the
first. Blocks `Type: Interface { }` are separate and do not count.

Wrong:

```wolf wrong
module main

types {
    struct Counter {
        value: Int
    }
}

impl {
    Counter {
        fn get(self) -> Int {
            self.value
        }
    }

    Counter {
        fn reset(mut self) {
            self.value = 0
        }
    }
}

functions {
    fn main() {
        var c = Counter { value: 3 }
        c.reset()
        print(c.get().to_string())
    }
}
```

Fixed:

```wolf fixed
module main

types {
    struct Counter {
        value: Int
    }
}

impl {
    Counter {
        fn get(self) -> Int {
            self.value
        }

        fn reset(mut self) {
            self.value = 0
        }
    }
}

functions {
    fn main() {
        var c = Counter { value: 3 }
        c.reset()
        print(c.get().to_string())
    }
}
```
