# E0210: second inherent `impl` block for a type

A type has two inherent `impl` blocks (blocks without an interface). All inherent methods of a
type are in one block; implementations of interfaces are separate blocks.

Wrong:

```wolf
module main

types {
    struct Counter {
        n: Int
    }
}

impl {
    Counter {
        fn get(self) -> Int { self.n }
    }

    Counter {
        fn twice(self) -> Int { self.n * 2 }
    }
}

functions {
    fn main() {
        let c = Counter { n: 2 }
        print(c.get().to_string() + c.twice().to_string())
    }
}
```

Fixed:

```wolf
module main

types {
    struct Counter {
        n: Int
    }
}

impl {
    Counter {
        fn get(self) -> Int { self.n }

        fn twice(self) -> Int { self.n * 2 }
    }
}

functions {
    fn main() {
        let c = Counter { n: 2 }
        print(c.get().to_string() + c.twice().to_string())
    }
}
```
