# E0411: unreachable `match` arm

A `match` arm can never be chosen, because the arms before it already cover every value it
would match. Remove it, or move it before the arm that hides it.

Wrong:

```wolf
module main

functions {
    fn main() {
        let n = 3
        match n {
            _ => print("any")
            3 => print("three")
        }
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let n = 3
        match n {
            3 => print("three")
            _ => print("any")
        }
    }
}
```
