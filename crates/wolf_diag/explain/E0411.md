# E0411: unreachable `match` arm

Arms are tried from top to bottom, and an earlier arm already matches every value this arm could
match, so it can never run. Remove the arm, or move it before the arm that covers it.

Wrong:

```wolf wrong
module main

main {
    print(name(1))
}

functions {
    fn name(n: Int) -> String {
        match n {
            _ => "any"
            0 => "zero"
        }
    }
}
```

Fixed:

```wolf fixed
module main

main {
    print(name(1))
}

functions {
    fn name(n: Int) -> String {
        match n {
            0 => "zero"
            _ => "any"
        }
    }
}
```
