# E0442: `where` that is not allowed here

`where T: Bound` after the signature of a method adds bounds to the type parameters of its `impl`
block, for that method only. It is allowed on the methods of a generic inherent block, and names
only the parameters of the block. A free function and a method's own type parameters take their
bounds in `<T: ...>`, and the methods of an interface and of an interface implementation take the
bounds the interface gives.

Wrong:

```wolf wrong
module main

main {
    print(same(1, 1).to_string())
}

functions {
    fn same<T>(a: T, b: T) -> Bool where T: Equatable {
        a == b
    }
}
```

Fixed:

```wolf fixed
module main

main {
    print(same(1, 1).to_string())
}

functions {
    fn same<T: Equatable>(a: T, b: T) -> Bool {
        a == b
    }
}
```
