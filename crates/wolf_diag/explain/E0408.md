# E0408: `?` in a function with an incompatible result type

`?` returns early with the `None` or `Err` of its operand, so the function must return an `Option`
for an `Option`, or a `Result` whose error type accepts the error.

Wrong:

```wolf
module main

functions {
    fn number(s: String) -> Int {
        s.parse_int()?
    }

    fn main() {
        print(number("4").to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn number(s: String) -> Result<Int, Error> {
        let n = s.parse_int()?
        Ok(n)
    }

    fn main() {
        match number("4") {
            Ok(n) => print(n.to_string())
            Err(e) => print(e.message())
        }
    }
}
```
