# E0408: `?` in a function with an incompatible result type

`?` returns early from the function with the error of a `Result` or with `None` of an `Option`, so
it can only be used in a function that returns the same kind: `Result` with an error type the error
converts to, or `Option`. Change the result type of the function, or handle the value with `match`.

Wrong:

```wolf wrong
module main

functions {
    fn parse(s: String) -> Result<Int, String> {
        if s.is_empty() {
            return Err("empty")
        }
        Ok(s.len())
    }

    fn total(s: String) -> Int {
        parse(s)? + 1
    }

    fn main() {
        print(total("12").to_string())
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn parse(s: String) -> Result<Int, String> {
        if s.is_empty() {
            return Err("empty")
        }
        Ok(s.len())
    }

    fn total(s: String) -> Result<Int, String> {
        Ok(parse(s)? + 1)
    }

    fn main() {
        match total("12") {
            Ok(n) => print(n.to_string())
            Err(e) => print(e)
        }
    }
}
```
