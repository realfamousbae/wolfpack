# E0615: unused import

A module or a name is imported but never used. Unused imports are errors, so that the list of
imports always shows what a module really depends on. Remove the import.

Wrong:

```wolf wrong
module main

imports {
    std.fs
}

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn main() {
        print("hi")
    }
}
```
