# E0615: unused import

An import is never used. Remove it, so that the imports show what the module depends on.

Wrong:

```wolf
module main

imports {
    std.list
}

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print("hi")
    }
}
```
