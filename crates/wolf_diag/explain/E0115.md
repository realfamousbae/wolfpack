# E0115: empty interpolation

The braces of an interpolated string `f"..."` must contain an expression. To write the characters
`{}` into the text, double them: `{{}}`.

Wrong:

```wolf wrong
module main

main {
    print(f"an empty map is written {}")
}
```

Fixed:

```wolf fixed
module main

main {
    print(f"an empty map is written {{}}")
}
```
