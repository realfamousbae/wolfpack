# E0315: label not before a loop

A label names a loop, so that `break label` and `continue label` can leave or continue it from a
loop inside. It is written before `while`, `for` or `loop`, on the same line. Anything else after
a label is an error.

Wrong:

```wolf wrong
module main

main {
    total: let sum = 1 + 2
    print(sum.to_string())
}
```

Fixed:

```wolf fixed
module main

main {
    let sum = 1 + 2
    print(sum.to_string())
}
```
