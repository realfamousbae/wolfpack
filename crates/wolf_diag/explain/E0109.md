# E0109: unescaped control character in a string

A string literal contains a control character (U+0000 to U+001F, or U+007F) written as itself, such
as a raw tab or an invisible bell character pasted from elsewhere. Control characters are invisible
in most editors, so they must be written as escapes: `\t`, `\n`, `\r`, `\0` or `\u{...}`.

Wrong:

The string holds the raw character U+0007 before the closing quote:

```text
    config {
        bell: String = "ding<U+0007>"
    }
```

Fixed:

```wolf fixed
module main

config {
    bell: String = "ding\u{7}"
}

functions {
    fn main() {
        print(bell.len().to_string())
    }
}
```
