# E0807: module cannot run in the VM

`wolf run --vm` and `wolf test --vm` run the program in the virtual machine of `wolf`, which runs
only wolfpack code and std. A module that the program imports, directly or through other modules,
calls code of the targets: it has an `extern` section, or it is a native module read from
`native/`. Such code exists only in TypeScript, Go or Rust, so the program cannot run in the VM.
Run it on a target instead, or write the function in wolfpack. The note shows the chain of
imports. This error comes only with `--vm`.

Wrong:

```text
// file: src/main.wolf
module main

extern {
    ts {
        fn shout(s: String) -> String from "String.prototype.toUpperCase"
    }
}

main {
    print(shout("hi"))
}

$ wolf run --vm
error[E0807]: module `main` cannot run in the VM
```

Fixed:

```wolf fixed
module main

main {
    print(shout("hi"))
}

functions {
    fn shout(s: String) -> String {
        s.to_upper_ascii()
    }
}
```
