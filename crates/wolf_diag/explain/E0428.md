# E0428: wrong number of arguments or wrong variant form

A call gives a different number of arguments than the function takes, or a variant is written in the
wrong form. A variant with values is written `Shape.Circle(1.0)`, a variant with named fields
`Shape.Rect { w: 1.0, h: 2.0 }`, and a variant without a payload `Shape.Empty`, without parentheses.
Patterns follow the same forms.

Wrong:

```wolf wrong
module main

types {
    enum Shape {
        Circle(Float)
        Rect { w: Float, h: Float }
        Empty
    }
}

main {
    let s = Shape.Rect(1.0, 2.0)
    let _ = s
}
```

Fixed:

```wolf fixed
module main

types {
    enum Shape {
        Circle(Float)
        Rect { w: Float, h: Float }
        Empty
    }
}

main {
    let s = Shape.Rect { w: 1.0, h: 2.0 }
    let _ = s
}
```
