# E0428: wrong number of arguments or wrong variant form

A call has the wrong number of arguments, or a variant is written in the wrong form: a variant
with a tuple payload is `Shape.Circle(1.0)`, one with named fields `Shape.Rect { w: 1.0 }`, one
without payload `Shape.Empty` without parentheses.

Wrong:

```wolf
module main

functions {
    fn twice(n: Int) -> Int { n * 2 }

    fn main() {
        print(twice(1, 2).to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn twice(n: Int) -> Int { n * 2 }

    fn main() {
        print(twice(1).to_string())
    }
}
```
