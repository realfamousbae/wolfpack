# E0414: `impl` outside the module of its type

Every `impl` block is in the module that declares its type, because Go allows methods only in the
package of the type. Methods cannot be added to built-in types such as `Int` or to types of other
modules. Write a free function instead, or move the block to the module of the type.

Wrong:

```wolf wrong
module main

impl {
    Int {
        fn double(self) -> Int {
            self * 2
        }
    }
}

main {
    print(2.double().to_string())
}
```

Fixed:

```wolf fixed
module main

main {
    print(double(2).to_string())
}

functions {
    fn double(n: Int) -> Int {
        n * 2
    }
}
```
