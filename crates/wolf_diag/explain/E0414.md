# E0414: `impl` outside the module of its type

An `impl` block is in another module than the type it is for. Methods and interface
implementations are written in the module that declares the type, so that they map onto Go
methods.

Wrong:

```text
// src/shapes.wolf declares `pub struct Circle`.
// src/main.wolf:
impl {
    shapes.Circle {
        fn area(self) -> Float { 0.0 }
    }
}
```

Fixed:

```text
// src/shapes.wolf:
impl {
    Circle {
        pub fn area(self) -> Float { 0.0 }
    }
}
```
