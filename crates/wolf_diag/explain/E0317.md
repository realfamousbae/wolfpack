# E0317: `||` in a condition with `let`

A condition of `if` or `while` may join `let` items and `Bool` expressions with `&&`: `if let
Some(x) = a && x > 0`. In such a condition every item ends at the next `&&`, so an `||` outside
parentheses would leave it unclear what it joins: the whole chain, or one item. Write the
alternatives in parentheses, as one item, or use nested `if`s.

Wrong:

```wolf wrong
module main

main {
    let found: Option<Int> = Some(4)
    let fallback = false
    if let Some(n) = found && n > 3 || fallback {
        print(n.to_string())
    }
}
```

Fixed:

```wolf fixed
module main

main {
    let found: Option<Int> = Some(4)
    let small = false
    if let Some(n) = found && (n > 3 || small) {
        print(n.to_string())
    }
}
```
