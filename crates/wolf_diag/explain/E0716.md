# E0716: no such native module

`wolf check --native native.<path>` prints what the compiler read from the code of one native
module: the files `native/ts/<path>.ts`, `native/go/<path>/` and `native/rust/<path>.rs` of the
project. This project has none of them for the module that was named. Check the spelling: the
path uses `.` between the parts and starts with `native`, as in an import.

Wrong:

```text
$ wolf check --native native.text.slugs
error[E0716]: no native module `native.text.slugs` in this project
  = help: name a module `native.<path>` with code in `native/ts/`, `native/go/` or `native/rust/`
```

Fixed:

```text
$ wolf check --native native.text.slug
// native.text.slug, read from `native/rust/text/slug.rs`
module native.text.slug
...
```
