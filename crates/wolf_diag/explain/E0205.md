# E0205: declaration in the wrong section

A declaration is inside a section where it does not belong: a `struct` inside `functions`, an
`fn` inside `types`. Each kind of declaration has its section: types in `types`, functions in
`functions` (also in `tests`), methods in `impl`.

Wrong:

```wolf
module main

functions {
    struct Point {
        x: Int
    }

    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

types {
    struct Point {
        x: Int
    }
}

functions {
    fn main() {
        let p = Point { x: 1 }
        print(p.x.to_string())
    }
}
```
