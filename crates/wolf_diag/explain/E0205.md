# E0205: declaration in the wrong section

Each kind of declaration has its own section: `struct`, `enum` and `type` go into `types`,
`interface` into `interfaces`, functions into `functions`, and so on. This declaration is in a
section that does not hold its kind. Move it to the section the help names.

Wrong:

```wolf wrong
module main

main {
    let p = Point { x: 1 }
    print(p.x.to_string())
}

functions {
    struct Point {
        x: Int
    }
}
```

Fixed:

```wolf fixed
module main

types {
    struct Point {
        x: Int
    }
}

main {
    let p = Point { x: 1 }
    print(p.x.to_string())
}
```
