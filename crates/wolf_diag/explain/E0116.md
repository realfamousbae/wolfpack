# E0116: malformed multiline string

A multiline string starts with `"""` at the end of a line and ends with `"""` on a line of its own.
The spaces or tabs before the closing `"""` are the indentation of the string: they are removed
from every line, so every line of the content must start with them.

Wrong:

```wolf wrong
module main

main {
    let help = """usage:
        wolf build
        """
    print(help)
}
```

Fixed:

```wolf fixed
module main

main {
    let help = """
        usage:
            wolf build
        """
    print(help)
}
```
