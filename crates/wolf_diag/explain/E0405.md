# E0405: operator not defined for these types

An operator is applied to operands it does not accept. Arithmetic needs two numbers of the same
type (`Int` with `Int`, `Float` with `Float`), `+` also joins two strings, `&&` and `||` take `Bool`.
Convert one side explicitly.

Wrong:

```wolf
module main

functions {
    fn main() {
        let total = 1 + 2.5
        print(total.to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let total = (1).to_float() + 2.5
        print(total.to_string())
    }
}
```
