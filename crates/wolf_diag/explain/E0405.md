# E0405: operator not defined for these types

An operator is applied to types it is not defined for. Arithmetic needs two numbers of the same type
(`Int` with `Int`, `Float` with `Float`), `+` also joins two strings, `&&`, `||` and `!` take
`Bool`, and `<` needs a `Comparable` type. Convert one side, for example with `.to_string()` or
`.to_float()`.

Wrong:

```wolf wrong
module main

main {
    let count = 5
    print("n=" + count)
}
```

Fixed:

```wolf fixed
module main

main {
    let count = 5
    print("n=" + count.to_string())
}
```
