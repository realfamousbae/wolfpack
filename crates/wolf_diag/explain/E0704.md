# E0704: module not available for the target

A build for a target includes every module that the program imports, directly or through other
modules. One of them uses extern names that have no declaration in the block of this target, so it
cannot be built for it. Declare the names in a block for the target, or build for a target that has
them. The note shows the chain of imports. This error comes from `wolf build`, `wolf run` and
`wolf test`, not from `wolf check`.

Wrong:

```text
// file: src/text.wolf
module text

extern {
    go {
        pub fn upper(s: String) -> String from "strings.ToUpper"
    }
}

$ wolf build --target ts
error[E0704]: module `text` is not available for `ts`
```

Fixed:

```wolf fixed
module main

imports {
    text.{upper}
}

functions {
    fn main() {
        print(upper("hi"))
    }
}

// file: src/text.wolf
module text

extern {
    ts {
        pub fn upper(s: String) -> String from "String.prototype.toUpperCase"
    }
    go {
        pub fn upper(s: String) -> String from "strings.ToUpper"
    }
}
```
