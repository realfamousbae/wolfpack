# E0704: module not available for the target

A module of the build declares an extern name for some targets only, so it cannot be built for
this one. Modules that import it, directly or not, are not available either; the message shows the
import chain. Declare the name for this target too, or build for a target that has it.

Wrong:

```text
extern {
    go {
        pub fn upper(s: String) -> String from "strings.ToUpper"
    }
}

$ wolf build --target ts
```

Fixed:

```text
extern {
    go {
        pub fn upper(s: String) -> String from "strings.ToUpper"
    }
    ts {
        pub fn upper(s: String) -> String from "String.prototype.toUpperCase"
    }
}
```
