# E0502: use of a value that may have been moved

The value is moved on some paths but not on others, for example inside an `if`, or it is moved
inside a loop and the next iteration would use it again. After the branch the compiler cannot know
whether it still exists. Move a copy, give the variable a new value on every path, or leave the loop
after the move.

Wrong:

```wolf wrong
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn take(own u: User) -> Int {
        u.tags.len()
    }

    fn main() {
        var u = User { name: "ann", tags: ["a"] }
        if u.tags.len() > 0 {
            let _ = take(own u)
        }
        print(u.name)
    }
}
```

Fixed:

```wolf fixed
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn take(own u: User) -> Int {
        u.tags.len()
    }

    fn main() {
        var u = User { name: "ann", tags: ["a"] }
        if u.tags.len() > 0 {
            let _ = take(u.copy())
        }
        print(u.name)
    }
}
```
