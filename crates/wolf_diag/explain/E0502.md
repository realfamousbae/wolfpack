# E0502: use of a value that may have been moved

A value may have been moved on some path: in one branch of an `if`, or in an earlier iteration of
a loop. After the branch or in the next iteration it cannot be used. Move it on every path, or move
a copy.

Wrong:

```wolf
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn make() -> User {
        User { name: "ann", tags: ["admin"] }
    }

    fn keep(own u: User) -> Int { u.tags.len() }

    fn main() {
        let u = make()
        if u.tags.is_empty() {
            print(keep(own u).to_string())
        }
        print(u.name)
    }
}
```

Fixed:

```wolf
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn make() -> User {
        User { name: "ann", tags: ["admin"] }
    }

    fn keep(own u: User) -> Int { u.tags.len() }

    fn main() {
        let u = make()
        if u.tags.is_empty() {
            print(keep(u.copy()).to_string())
        }
        print(u.name)
    }
}
```
