# E0606: name declared twice in the same block

A block declares the same name twice, or declares a variable with the name of a parameter of its
function. Wolfpack has no shadowing in one block: a name may be reused only in a nested block.
Rename the second one, or assign to a `var` instead.

Wrong:

```wolf wrong
module main

main {
    let a = 1
    let a = 2
    print(a.to_string())
}
```

Fixed:

```wolf fixed
module main

main {
    let a = 1
    let b = a + 1
    print(b.to_string())
}
```
