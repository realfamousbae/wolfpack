# E0606: name declared twice in the same block

A name is declared twice in one block. Wolfpack has no shadowing inside a block: give the second
variable another name, or change the first one (declare it with `var`).

Wrong:

```wolf
module main

functions {
    fn main() {
        let a = 1
        let a = 2
        print(a.to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        var a = 1
        a = 2
        print(a.to_string())
    }
}
```
