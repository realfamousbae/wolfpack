# E0504: move out of a borrowed value

A value that is only borrowed (a read or `mut` parameter, or the value of a `for` loop) cannot be
moved, for example returned as a whole or in part. Return a copy.

Wrong:

```wolf
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn make() -> User {
        User { name: "ann", tags: ["admin"] }
    }

    fn name_of(u: User) -> String {
        u.name
    }

    fn main() {
        print(name_of(make()))
    }
}
```

Fixed:

```wolf
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn make() -> User {
        User { name: "ann", tags: ["admin"] }
    }

    fn name_of(u: User) -> String {
        u.name.copy()
    }

    fn main() {
        print(name_of(make()))
    }
}
```
