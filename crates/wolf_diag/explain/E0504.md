# E0504: move out of a borrowed value

A parameter without a mode, and `self` in a method with plain `self`, is only borrowed: the caller
keeps the value. Returning it, or a part of it, would move it out of the caller. Return a copy, or
declare the parameter `own` so that the caller hands the value over.

Wrong:

```wolf wrong
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn name_of(u: User) -> String {
        u.name
    }

    fn main() {
        let u = User { name: "ann", tags: ["a"] }
        print(name_of(u))
    }
}
```

Fixed:

```wolf fixed
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn name_of(u: User) -> String {
        u.name.copy()
    }

    fn main() {
        let u = User { name: "ann", tags: ["a"] }
        print(name_of(u))
    }
}
```
