# E0443: missing or misplaced `override`

A method of an interface may have a body, its default. A type that implements the interface gets
the default when its block leaves the method out, and replaces it with a method written
`override fn`. Without `override`, a method with the name of a default is this error, so that a
replacement is never written by accident; and so is `override` on a method that has no default,
in an inherent block, in an interface or on a free function.

Wrong:

```wolf wrong
module main

types {
    struct Dog {
        title: String
    }
}

interfaces {
    interface Named {
        fn name(self) -> String

        fn greeting(self) -> String {
            "Hello, " + self.name()
        }
    }
}

impl {
    Dog: Named {
        fn name(self) -> String {
            self.title.copy()
        }

        fn greeting(self) -> String {
            "Woof"
        }
    }
}

main {
    print(Dog { title: "Rex" }.greeting())
}
```

Fixed:

```wolf fixed
module main

types {
    struct Dog {
        title: String
    }
}

interfaces {
    interface Named {
        fn name(self) -> String

        fn greeting(self) -> String {
            "Hello, " + self.name()
        }
    }
}

impl {
    Dog: Named {
        fn name(self) -> String {
            self.title.copy()
        }

        override fn greeting(self) -> String {
            "Woof"
        }
    }
}

main {
    print(Dog { title: "Rex" }.greeting())
}
```
