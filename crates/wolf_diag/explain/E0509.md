# E0509: access to a borrowed place

A `for` loop reads its list for the whole body, and a `match` arm reads its subject for the whole
arm. Changing or moving that place inside the loop or the arm is not allowed. Collect the changes
and apply them after the loop, or loop over a copy.

Wrong:

```wolf wrong
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

main {
    var u = User { name: "ann", tags: ["a"] }
    for t in u.tags {
        u.tags.push(t.copy())
    }
    print(u.tags.len().to_string())
}
```

Fixed:

```wolf fixed
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

main {
    var u = User { name: "ann", tags: ["a"] }
    for t in u.tags.copy() {
        u.tags.push(t.copy())
    }
    print(u.tags.len().to_string())
}
```
