# E0509: access to a borrowed place

A place is changed or moved while it is borrowed by a `for` loop over it or by a `match` on it,
for example a list that grows while the loop walks over it. Collect the changes first and apply them
after the loop.

Wrong:

```wolf
module main

functions {
    fn main() {
        var items = [1, 2]
        for x in items {
            items.push(x)
        }
        print(items.len().to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        var items = [1, 2]
        let more = items.copy()
        for x in more {
            items.push(x)
        }
        print(items.len().to_string())
    }
}
```
