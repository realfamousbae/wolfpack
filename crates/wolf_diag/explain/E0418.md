# E0418: infinitely sized struct

A struct contains itself, directly or through other structs, so its values would be infinitely
large. Put the recursive field in an `Option`, a `List` or an enum variant.

Wrong:

```wolf
module main

types {
    struct Node {
        value: Int
        next: Node
    }
}

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

types {
    struct Node {
        value: Int
        next: Option<Node>
    }
}

functions {
    fn main() {
        let n = Node { value: 1, next: None }
        print(n.value.to_string())
    }
}
```
