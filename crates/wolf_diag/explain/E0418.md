# E0418: infinitely sized struct

A struct contains a field of its own type, directly or through other structs, so a value would need
infinite space. Store the recursive part in an `Option<...>`, a `List<...>` or an enum variant,
which may be empty.

Wrong:

```wolf wrong
module main

types {
    struct Node {
        value: Int
        next: Node
    }
}

functions {
    fn main() {
        let n = Node { value: 1, next: Node { value: 2, next: None } }
        print(n.value.to_string())
    }
}
```

Fixed:

```wolf fixed
module main

types {
    struct Node {
        value: Int
        next: Option<Node>
    }
}

functions {
    fn main() {
        let n = Node { value: 1, next: None }
        print(n.value.to_string())
    }
}
```
