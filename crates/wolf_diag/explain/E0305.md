# E0305: chained comparison

Comparisons cannot be chained: `a < b < c` would compare a `Bool` with `c`. Combine two
comparisons with `&&`.

Wrong:

```wolf
module main

functions {
    fn main() {
        let x = 5
        print((1 < x < 10).to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let x = 5
        print((1 < x && x < 10).to_string())
    }
}
```
