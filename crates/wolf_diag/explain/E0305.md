# E0305: chained comparison

`a < b < c` does not mean what it means in mathematics: it would compare a `Bool` with `c`, and
`a == b == c` compares the result of `a == b` with `c`. Comparison operators cannot be chained; join
two comparisons with `&&`.

Wrong:

```wolf wrong
module main

main {
    print(same(true, true, false).to_string())
}

functions {
    fn same(a: Bool, b: Bool, c: Bool) -> Bool {
        a == b == c
    }
}
```

Fixed:

```wolf fixed
module main

main {
    print(same(true, true, false).to_string())
}

functions {
    fn same(a: Bool, b: Bool, c: Bool) -> Bool {
        a == b && b == c
    }
}
```
