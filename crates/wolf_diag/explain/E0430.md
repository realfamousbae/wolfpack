# E0430: `break` or `continue` outside a loop

`break` and `continue` work only inside a `for` or `while` loop. The body of a closure is not part
of the loop around it, so they cannot be used there either; use an `if` inside the closure instead.

Wrong:

```wolf wrong
module main

main {
    for i in 0..3 {
        let skip = |n: Int| {
            if n == 1 {
                continue
            }
            print(n.to_string())
        }
        skip(i)
    }
}
```

Fixed:

```wolf fixed
module main

main {
    for i in 0..3 {
        let show = |n: Int| {
            if n != 1 {
                print(n.to_string())
            }
        }
        show(i)
    }
}
```
