# E0430: `break` or `continue` outside a loop

`break` and `continue` are allowed only inside a `while` or `for` loop, and not inside a closure
in a loop.

Wrong:

```wolf
module main

functions {
    fn main() {
        if true {
            break
        }
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        while true {
            break
        }
    }
}
```
