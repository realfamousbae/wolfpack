# E0445: a super-interface that is not allowed

An interface may name other interfaces after `:`, its super-interfaces: a type that implements
`interface Greeter: Named` implements `Named` too. A super-interface must be an interface of the
program, `Error`, `Comparable` or `Display`. It cannot be another kind of type, one of the
derived or closed interfaces `Equatable`, `Copyable` and `Hashable` (no block implements them),
the interface itself, directly or through others, or the same interface twice.

Wrong:

```wolf wrong
module main

interfaces {
    interface Named {
        fn name(self) -> String
    }

    interface Greeter: Named + Named {
        fn greeting(self) -> String
    }
}

main {
    print("ok")
}
```

Fixed:

```wolf fixed
module main

interfaces {
    interface Named {
        fn name(self) -> String
    }

    interface Greeter: Named {
        fn greeting(self) -> String
    }
}

main {
    print("ok")
}
```
