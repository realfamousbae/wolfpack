# E0607: private item used outside its module

An item, field or method of another module is used, but it is not `pub`. Mark it `pub` in its
module if other modules should use it.

Wrong:

```text
// src/users/model.wolf
functions {
    fn secret() -> Int { 1 }
}

// src/main.wolf
print(model.secret().to_string())
```

Fixed:

```text
// src/users/model.wolf
functions {
    pub fn secret() -> Int { 1 }
}
```
