# E0607: private item used outside its module

An item without `pub` is private to its module: other modules cannot use it, call its private
methods or read its private fields. A struct with a private field can be built only in its own
module. Mark the item `pub`, or use a public function of its module.

Wrong:

```wolf wrong
module main

imports {
    users.{User}
}

functions {
    fn main() {
        let u = User { name: "ann", secret: "x" }
        print(u.name)
    }
}

// file: src/users.wolf
module users

types {
    pub struct User {
        pub name: String
        secret: String
    }
}
```

Fixed:

```wolf fixed
module main

imports {
    users.{make}
}

functions {
    fn main() {
        let u = make("ann")
        print(u.name)
    }
}

// file: src/users.wolf
module users

types {
    pub struct User {
        pub name: String
        secret: String
    }
}

impl {
    User {
        pub fn secret_length(self) -> Int {
            self.secret.len()
        }
    }
}

functions {
    pub fn make(name: String) -> User {
        User { name: name.copy(), secret: "x" }
    }
}
```
