# E0410: non-exhaustive `match`

A `match` does not cover every value of the matched type. The message names a missing case. Add
an arm for it, or `_ => ...` for the rest.

Wrong:

```wolf
module main

types {
    enum Shape {
        Circle(Float)
        Square(Float)
    }
}

functions {
    fn name(s: Shape) -> String {
        match s {
            Shape.Circle(_) => "circle"
        }
    }

    fn main() {
        print(name(Shape.Square(1.0)))
    }
}
```

Fixed:

```wolf
module main

types {
    enum Shape {
        Circle(Float)
        Square(Float)
    }
}

functions {
    fn name(s: Shape) -> String {
        match s {
            Shape.Circle(_) => "circle"
            Shape.Square(_) => "square"
        }
    }

    fn main() {
        print(name(Shape.Square(1.0)))
    }
}
```
