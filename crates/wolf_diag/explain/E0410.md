# E0410: non-exhaustive `match`

A `match` must cover every possible value of its subject. The message names a value that no arm
matches. Add an arm for it, or a final `_ => ...` arm for all the rest. Guards (`x if x > 0`) do not
count as covering, since the compiler cannot prove them.

Wrong:

```wolf wrong
module main

main {
    print(name(1))
}

functions {
    fn name(n: Int) -> String {
        match n {
            0 => "zero"
            1 => "one"
        }
    }
}
```

Fixed:

```wolf fixed
module main

main {
    print(name(1))
}

functions {
    fn name(n: Int) -> String {
        match n {
            0 => "zero"
            1 => "one"
            _ => "many"
        }
    }
}
```
