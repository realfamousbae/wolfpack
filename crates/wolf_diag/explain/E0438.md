# E0438: label of an enclosing loop reused

A loop inside another loop cannot have the same label, because `break label` would not say which
of them it leaves. Give the inner loop another label.

Wrong:

```wolf wrong
module main

main {
    rows: for i in 0..3 {
        rows: for j in 0..3 {
            if i == j {
                continue rows
            }
        }
    }
}
```

Fixed:

```wolf fixed
module main

main {
    rows: for i in 0..3 {
        cols: for j in 0..3 {
            if i == j {
                continue rows
            }
            if j > 1 {
                break cols
            }
        }
    }
}
```
