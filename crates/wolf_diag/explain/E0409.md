# E0409: unhandled `Result` value

A call returns a `Result`, and the result is dropped without looking at it, so an error would pass
unnoticed. Handle it with `match` or `?`, or discard it on purpose with `let _ = ...`.

Wrong:

```wolf wrong
module main

imports {
    std.fs
}

functions {
    fn main() {
        fs.write_text("out.txt", "data")
    }
}
```

Fixed:

```wolf fixed
module main

imports {
    std.fs
}

functions {
    fn main() {
        match fs.write_text("out.txt", "data") {
            Ok(_) => print("saved")
            Err(e) => print(e.message())
        }
    }
}
```
