# E0409: unhandled `Result` value

A `Result` is computed and then dropped: an error would be lost silently. Handle it with `?`,
`match` or `if let`, or say that you ignore it with `let _ = ...`.

Wrong:

```wolf
module main

imports {
    std.fs
}

functions {
    fn main() {
        fs.write_text("out.txt", "data")
    }
}
```

Fixed:

```wolf
module main

imports {
    std.fs
}

functions {
    fn main() {
        match fs.write_text("out.txt", "data") {
            Ok(_) => print("saved")
            Err(e) => print(e.message())
        }
    }
}
```
