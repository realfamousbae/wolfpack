# E0313: two statements on one line

Two statements are on one line. There is no `;` in Wolfpack; put each statement on its own
line.

Wrong:

```wolf
module main

functions {
    fn main() {
        let a = 1 let b = 2
        print((a + b).to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let a = 1
        let b = 2
        print((a + b).to_string())
    }
}
```
