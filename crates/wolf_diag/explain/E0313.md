# E0313: two statements on one line

A line break ends a statement and there is no `;`, so each statement goes on its own line.

Wrong:

```wolf wrong
module main

main {
    let a = 1 let b = 2
    print((a + b).to_string())
}
```

Fixed:

```wolf fixed
module main

main {
    let a = 1
    let b = 2
    print((a + b).to_string())
}
```
