# E0117: malformed format specification

An interpolation may end with a format specification after a `:`, written
`[[fill] align] [0] [width] [.precision]`: `{price:>8.2}` writes `price` with two digits after
the point, aligned to the right in eight characters. The alignment is `<`, `^` or `>`, and a fill
character before it replaces the spaces. `0` pads a number with zeros after its sign, and cannot
be combined with a fill or an alignment. The width is at most 1000 and the precision at most 100.
Anything else after the `:` is this error, and so is a `:` with nothing after it.

Wrong:

```wolf wrong
module main

main {
    let n = 42
    print(f"{n:<05}")
}
```

Fixed:

```wolf fixed
module main

main {
    let n = 42
    print(f"{n:05}")
}
```
