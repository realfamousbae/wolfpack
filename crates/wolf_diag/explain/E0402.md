# E0402: unknown type name

A type name is not declared, not imported, or misspelled. Types of other modules are imported in
`imports` (`users.model.{User}`) or written with the module (`model.User`).

Wrong:

```wolf
module main

functions {
    fn twice(n: Integer) -> Int { n * 2 }

    fn main() {
        print(twice(2).to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn twice(n: Int) -> Int { n * 2 }

    fn main() {
        print(twice(2).to_string())
    }
}
```
