# E0402: unknown type name

The name used as a type is not a type in scope: it may be misspelled, not imported, or the name of a
function or a constant. Types come from the `types` section of the module, from `imports`, or from
the prelude (`Int`, `String`, `List`, `Option` and so on).

Wrong:

```wolf wrong
module main

types {
    struct User {
        name: Strng
    }
}

main {
    let u = User { name: "ann" }
    print(u.name)
}
```

Fixed:

```wolf fixed
module main

types {
    struct User {
        name: String
    }
}

main {
    let u = User { name: "ann" }
    print(u.name)
}
```
