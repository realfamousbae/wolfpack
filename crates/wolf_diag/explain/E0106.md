# E0106: integer literal too large

`Int` is a signed 64-bit integer on every target, so an integer literal is at most
9223372036854775807 (`std.math.int_max`). Use a smaller value, or a `Float` if the exact value is
not needed.

Wrong:

```wolf wrong
module main

config {
    big: Int = 10000000000000000000
}

main {
    print(big.to_string())
}
```

Fixed:

```wolf fixed
module main

config {
    big: Int = 9223372036854775807
}

main {
    print(big.to_string())
}
```
