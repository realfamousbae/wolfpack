# E0106: integer literal too large

An integer literal is larger than the largest `Int`, `9223372036854775807`. The literal
`9223372036854775808` is allowed only after a minus sign, as the smallest `Int`.

Wrong:

```wolf
module main

functions {
    fn main() {
        print((99999999999999999999).to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print((9223372036854775807).to_string())
    }
}
```
