# E0446: a super-interface that the type does not implement

A type that implements an interface must implement each of its super-interfaces too, each in a
block of its own: `Dog: Greeter { ... }` for `interface Greeter: Named` needs `Dog: Named { ...
}`. For a generic type, the head of the block must give what the implementation of the
super-interface needs: with `Bag<T: Named>: Named`, the block is `Bag<T: Named>: Greeter`.

Wrong:

```wolf wrong
module main

types {
    struct Dog {
        title: String
    }
}

interfaces {
    interface Named {
        fn name(self) -> String
    }

    interface Greeter: Named {
        fn greeting(self) -> String {
            "Hello, " + self.name()
        }
    }
}

impl {
    Dog: Greeter {}
}

main {
    print(Dog { title: "Rex" }.greeting())
}
```

Fixed:

```wolf fixed
module main

types {
    struct Dog {
        title: String
    }
}

interfaces {
    interface Named {
        fn name(self) -> String
    }

    interface Greeter: Named {
        fn greeting(self) -> String {
            "Hello, " + self.name()
        }
    }
}

impl {
    Dog: Named {
        fn name(self) -> String { self.title.copy() }
    }

    Dog: Greeter {}
}

main {
    print(Dog { title: "Rex" }.greeting())
}
```
