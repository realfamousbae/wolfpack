# E0714: native file cannot be read

The compiler reads the declarations of the files of a native module, and this one has a syntax
error in its own language. The note shows the line, the column and the message of the parser.

Wrong:

```wolf wrong
module main

imports {
    native.slug
}

main {
    print(slug.slugify("A B"))
}

// file: native/rust/slug.rs
pub fn slugify(s: &str) -> String {
    s.to_lowercase(
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "cli"

[targets]
default = "rust"
```

Fixed:

```wolf fixed
module main

imports {
    native.slug
}

main {
    print(slug.slugify("A B"))
}

// file: native/rust/slug.rs
pub fn slugify(s: &str) -> String {
    s.to_lowercase()
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "cli"

[targets]
default = "rust"
```
