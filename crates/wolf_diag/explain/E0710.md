# E0710: native code takes a generated path

`wolf build` copies the files of `native/<target>/` into the generated project, next to files that
it generates itself. A native file may not take the place of a generated one: `native/rust/mod.rs`
would replace the generated `src/native/mod.rs`, which declares the modules of `native/rust/`, and
a module `native` of `src/` would be generated where the native files are copied.

Wrong:

```wolf wrong
module main

main {
    print("hi")
}

// file: native/rust/mod.rs
pub fn twice(n: i64) -> i64 {
    n * 2
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "cli"

[targets]
default = "rust"
```

Fixed:

```wolf fixed
module main

main {
    print("hi")
}

// file: native/rust/util.rs
pub fn twice(n: i64) -> i64 {
    n * 2
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "cli"

[targets]
default = "rust"
```
