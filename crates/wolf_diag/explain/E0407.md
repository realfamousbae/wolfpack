# E0407: map key type is not `Hashable`

Map keys must be `Hashable`: `Int`, `String`, `Bool` and enums without payloads. A struct or a
`Float` cannot be a key; use a field of it, or its text.

Wrong:

```wolf
module main

functions {
    fn main() {
        let m: Map<Float, String> = [:]
        print(m.len().to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let m: Map<Int, String> = [:]
        print(m.len().to_string())
    }
}
```
