# E0407: map key type is not `Hashable`

Map keys must be `Hashable`: `Int`, `String`, `Bool` or an enum without payloads. These are the
types that every target can use as keys by value. Use one of them as the key, for example a name or
an id instead of a whole struct, or a `String` built from the value.

Wrong:

```wolf wrong
module main

functions {
    fn main() {
        var prices: Map<Float, String> = [:]
        prices[1.5] = "cheap"
        print(prices.len().to_string())
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn main() {
        var prices: Map<Int, String> = [:]
        prices[150] = "cheap"
        print(prices.len().to_string())
    }
}
```
