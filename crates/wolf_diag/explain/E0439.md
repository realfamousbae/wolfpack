# E0439: struct literal or pattern of a name that is not a struct

A struct literal `Name { field: value }` builds a struct, and a struct pattern `Name { field }`
takes one apart. `Name` must be a struct, an alias of a struct, or a variant with named fields
(`Shape.Rect { w, h }`). A built-in type, an enum, an interface or a function has no fields to
write this way; for an enum, name one of its variants.

Wrong:

```wolf wrong
module main

types {
    enum Shape {
        Dot
        Rect { w: Float, h: Float }
    }
}

main {
    let r = Shape { w: 2.0, h: 3.0 }
    let _ = r
}
```

Fixed:

```wolf fixed
module main

types {
    enum Shape {
        Dot
        Rect { w: Float, h: Float }
    }
}

main {
    let r = Shape.Rect { w: 2.0, h: 3.0 }
    let _ = r
}
```
