# E0510: capture of a borrowed value

Closures capture values by moving them in, and a borrowed value, such as a plain parameter, cannot
be moved. Copy it into a local variable first and let the closure capture the copy.

Wrong:

```wolf wrong
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn names(u: User) -> List<String> {
        ["x"].map(|s| s + u.name)
    }

    fn main() {
        let u = User { name: "ann", tags: ["a"] }
        print(names(u).len().to_string())
    }
}
```

Fixed:

```wolf fixed
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn names(u: User) -> List<String> {
        let name = u.name.copy()
        ["x"].map(|s| s + name)
    }

    fn main() {
        let u = User { name: "ann", tags: ["a"] }
        print(names(u).len().to_string())
    }
}
```
