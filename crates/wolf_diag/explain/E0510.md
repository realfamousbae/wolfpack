# E0510: capture of a borrowed value

A closure captures a value that is only borrowed, such as a read parameter. The closure could be
called after the borrow ends. Capture a copy instead.

Wrong:

```wolf
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn make() -> User {
        User { name: "ann", tags: ["admin"] }
    }

    fn greet_all(u: User) -> List<String> {
        ["hi "].map(|s| s + u.name)
    }

    fn main() {
        print(greet_all(make()).len().to_string())
    }
}
```

Fixed:

```wolf
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn make() -> User {
        User { name: "ann", tags: ["admin"] }
    }

    fn greet_all(u: User) -> List<String> {
        let name = u.name.copy()
        ["hi "].map(|s| s + name)
    }

    fn main() {
        print(greet_all(make()).len().to_string())
    }
}
```
