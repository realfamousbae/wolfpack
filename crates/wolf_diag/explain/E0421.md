# E0421: function may end without a value

A function with a result type must produce a value on every path: the body ends with a value, or
every path ends with `return`. Here some path reaches the end of the body without one, for example
an `if` without `else` or a loop that may stop.

Wrong:

```wolf wrong
module main

main {
    print(sign(1))
}

functions {
    fn sign(n: Int) -> String {
        if n < 0 {
            return "negative"
        }
    }
}
```

Fixed:

```wolf fixed
module main

main {
    print(sign(1))
}

functions {
    fn sign(n: Int) -> String {
        if n < 0 {
            return "negative"
        }
        "positive"
    }
}
```
