# E0421: function may end without a value

A function with a result type may reach its end without producing a value, for example when an
`if` without `else` is the last statement.

Wrong:

```wolf
module main

functions {
    fn sign(n: Int) -> String {
        if n < 0 {
            return "negative"
        }
    }

    fn main() {
        print(sign(1))
    }
}
```

Fixed:

```wolf
module main

functions {
    fn sign(n: Int) -> String {
        if n < 0 {
            return "negative"
        }
        "positive"
    }

    fn main() {
        print(sign(1))
    }
}
```
