# E0406: type is not `Equatable` or not `Copyable`

`==` needs an `Equatable` type and `.copy()` a `Copyable` one. Structs and enums get both from their
fields, so a type with a field of a function type has neither, and interface values are not
`Equatable`. A type parameter has them only when it is declared with the bound: `T: Equatable`.

Wrong:

```wolf wrong
module main

main {
    print(same(1, 2).to_string())
}

functions {
    fn same<T>(a: T, b: T) -> Bool {
        a == b
    }
}
```

Fixed:

```wolf fixed
module main

main {
    print(same(1, 2).to_string())
}

functions {
    fn same<T: Equatable>(a: T, b: T) -> Bool {
        a == b
    }
}
```
