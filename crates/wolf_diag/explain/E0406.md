# E0406: type is not `Equatable` or not `Copyable`

`==` needs a type that is `Equatable`, and `.copy()` one that is `Copyable`. Structs and enums are
both when all their fields are; functions and interface values are neither. A type parameter needs
the bound written: `T: Equatable`.

Wrong:

```wolf
module main

functions {
    fn same<T>(a: T, b: T) -> Bool { a == b }

    fn main() {
        print(same(1, 1).to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn same<T: Equatable>(a: T, b: T) -> Bool { a == b }

    fn main() {
        print(same(1, 1).to_string())
    }
}
```
