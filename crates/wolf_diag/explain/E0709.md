# E0709: native code not found

A `native:` path names code of the project in `native/<target>/`, and that file, package or module
does not exist. In TypeScript `native:text/slug#slugify` needs `native/ts/text/slug.ts`; in Go
`native:slug.Slugify` needs a Go file in `native/go/slug/`; in Rust `native:slug::slugify` needs
`native/rust/slug.rs` (or `native/rust/slug/mod.rs`). Whether the function itself exists is checked
by the tools of the target when the project is built.

Wrong:

```wolf wrong
module main

extern {
    ts {
        fn slugify(s: String) -> String from "native:slug#slugify"
    }
}

main {
    print(slugify("Hello World"))
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "cli"

[targets]
default = "ts"
```

Fixed:

```wolf fixed
module main

extern {
    ts {
        fn slugify(s: String) -> String from "native:slug#slugify"
    }
}

main {
    print(slugify("Hello World"))
}

// file: native/ts/slug.ts
export function slugify(s: string): string {
  return s.toLowerCase().split(" ").join("-");
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "cli"

[targets]
default = "ts"
```
