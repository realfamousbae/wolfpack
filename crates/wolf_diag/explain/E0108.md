# E0108: float literal out of range

A float literal is too large to be a `Float` (it would be infinite). The largest `Float` is about
`1.8e308`. Write `1.0 / 0.0` if you want infinity.

Wrong:

```wolf
module main

functions {
    fn main() {
        print((1e999).to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print((1e300).to_string())
    }
}
```
