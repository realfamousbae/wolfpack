# E0108: float literal out of range

A `Float` is a 64-bit IEEE number; its largest finite value is about 1.8e308. A literal beyond that
would be infinite. Write a smaller value.

Wrong:

```wolf wrong
module main

config {
    huge: Float = 1.0e999
}

functions {
    fn main() {
        print(huge.to_string())
    }
}
```

Fixed:

```wolf fixed
module main

config {
    huge: Float = 1.0e300
}

functions {
    fn main() {
        print(huge.to_string())
    }
}
```
