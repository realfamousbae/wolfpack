# E0112: unterminated block comment

A `/*` comment is not closed before the end of the file. Block comments nest: every `/*`, also one
inside a comment, needs its own `*/`. Close each of them, or use `//` line comments.

Wrong:

```wolf wrong
module main

config {
    limit: Int = 1
}

functions {
    fn main() {
        print(limit.to_string())
    }
}

/* to do: /* a second limit */
```

Fixed:

```wolf fixed
module main

config {
    limit: Int = 1
}

functions {
    fn main() {
        print(limit.to_string())
    }
}

/* to do: /* a second limit */ */
```
