# E0112: unterminated block comment

A block comment `/* ... */` is not closed before the end of the file. Block comments nest, so
every `/*` inside needs its own `*/`.

Wrong:

```wolf
module main

functions {
    /* draft /* old */
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

functions {
    /* draft /* old */ */
    fn main() {
        print("hi")
    }
}
```
