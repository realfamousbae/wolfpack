# E0207: declaration outside any section

Every declaration lives inside a section; there are no free-standing items at the top level of a
file. Put the declaration into the section the help names.

Wrong:

```wolf wrong
module main

main {
    print("hi")
}

fn twice(x: Int) -> Int {
    x * 2
}
```

Fixed:

```wolf fixed
module main

main {
    print(twice(2).to_string())
}

functions {
    fn twice(x: Int) -> Int {
        x * 2
    }
}
```
