# E0413: wrong methods in an interface implementation

A block `Type: Interface { }` must implement every method of the interface, each with exactly the
signature the interface declares, including the receiver (`self`, `mut self` or `own self`), and
nothing else. Other methods of the type go into its inherent block `Type { }`.

Wrong:

```wolf wrong
module main

types {
    struct Rect {
        w: Float
    }
}

interfaces {
    interface Shape {
        fn area(self) -> Float
    }
}

impl {
    Rect: Shape {
        fn area(mut self) -> Float {
            self.w * self.w
        }
    }
}

functions {
    fn main() {
        let r = Rect { w: 2.0 }
        print(r.area().to_string())
    }
}
```

Fixed:

```wolf fixed
module main

types {
    struct Rect {
        w: Float
    }
}

interfaces {
    interface Shape {
        fn area(self) -> Float
    }
}

impl {
    Rect: Shape {
        fn area(self) -> Float {
            self.w * self.w
        }
    }
}

functions {
    fn main() {
        let r = Rect { w: 2.0 }
        print(r.area().to_string())
    }
}
```
