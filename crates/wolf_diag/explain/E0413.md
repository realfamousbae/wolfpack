# E0413: wrong methods in an interface implementation

An interface implementation must have exactly the methods of the interface, with the same
signatures: none missing, none extra, the same modes of `self` and of the parameters.

Wrong:

```wolf
module main

types {
    struct Dog {
        name: String
    }
}

interfaces {
    interface Named {
        fn name(self) -> String
    }
}

impl {
    Dog: Named {
        fn title(self) -> String { self.name.copy() }
    }
}

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

types {
    struct Dog {
        name: String
    }
}

interfaces {
    interface Named {
        fn name(self) -> String
    }
}

impl {
    Dog: Named {
        fn name(self) -> String { self.name.copy() }
    }
}

functions {
    fn main() {
        let d = Dog { name: "rex" }
        print(d.name())
    }
}
```
