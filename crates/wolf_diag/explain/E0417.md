# E0417: invalid interface member

Interface members are methods with `self` and without type parameters. A function without `self`
(a constructor) or a generic method cannot be in an interface.

Wrong:

```wolf
module main

interfaces {
    interface Store {
        fn create() -> Int
    }
}

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

interfaces {
    interface Store {
        fn size(self) -> Int
    }
}

functions {
    fn main() {
        print("hi")
    }
}
```
