# E0417: invalid interface member

Interface members are methods: each has a `self` parameter and no type parameters of its own. Go
interfaces and Rust trait objects cannot have generic methods. Put the type parameter on the
interface, or make the function a free function or an inherent method.

Wrong:

```wolf wrong
module main

interfaces {
    interface Store {
        fn create() -> Int
    }
}

main {
    print("hi")
}
```

Fixed:

```wolf fixed
module main

interfaces {
    interface Store {
        fn create(self) -> Int
    }
}

main {
    print("hi")
}
```
