# E0312: float literal in a pattern

Patterns compare with `==`, and comparing floats for equality is rarely what is meant (`0.1 + 0.2`
is not `0.3`). Float literals are not allowed in patterns; compare with `<` and `>` in an `if`
instead.

Wrong:

```wolf wrong
module main

main {
    print(name(1.5))
}

functions {
    fn name(x: Float) -> String {
        match x {
            1.5 => "one and a half"
            _ => "other"
        }
    }
}
```

Fixed:

```wolf fixed
module main

main {
    print(name(1.5))
}

functions {
    fn name(x: Float) -> String {
        if x > 1.49 && x < 1.51 {
            "one and a half"
        } else {
            "other"
        }
    }
}
```
