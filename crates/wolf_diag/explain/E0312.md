# E0312: float literal in a pattern

A float literal cannot be a pattern: comparing floats for equality is unreliable. Use a guard
with a comparison instead.

Wrong:

```wolf
module main

functions {
    fn main() {
        let x = 0.5
        match x {
            0.5 => print("half")
            _ => print("other")
        }
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let x = 0.5
        match x {
            v if v == 0.5 => print("half")
            _ => print("other")
        }
    }
}
```
