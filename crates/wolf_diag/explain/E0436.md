# E0436: unknown loop label

`break label` and `continue label` name a loop around them by its label. No enclosing loop has
this label: it may be misspelled, or the loop is outside the closure the `break` is in.

Wrong:

```wolf wrong
module main

main {
    rows: for i in 0..3 {
        for j in 0..3 {
            if j > i {
                continue row
            }
            print(f"{i} {j}")
        }
    }
}
```

Fixed:

```wolf fixed
module main

main {
    rows: for i in 0..3 {
        for j in 0..3 {
            if j > i {
                continue rows
            }
            print(f"{i} {j}")
        }
    }
}
```
