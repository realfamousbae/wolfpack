# E0425: expression value is not used

An expression statement computes a value and drops it, which does nothing. Often the line was meant
to continue the line above: a line break ends a statement, so the operator must end the first line.
Otherwise store the value with `let` or remove it.

Wrong:

```wolf wrong
module main

functions {
    fn main() {
        let price = 10
        let total = price
            - 2
        print(total.to_string())
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn main() {
        let price = 10
        let total = price -
            2
        print(total.to_string())
    }
}
```
