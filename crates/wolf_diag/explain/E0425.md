# E0425: expression value is not used

A statement computes a value that nobody uses, such as a lone variable or `a + b`. Remove it,
store the value with `let`, or print it.

Wrong:

```wolf
module main

functions {
    fn main() {
        let a = 1
        a + 1
        print(a.to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let a = 1
        print((a + 1).to_string())
    }
}
```
