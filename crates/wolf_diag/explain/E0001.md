# E0001: cannot read a file or directory

`wolf` could not read a file or a directory it needs: a path given on the command line, a source
file of the project, or `wolfpack.toml`. The message names the path and what the system reported,
for example that the file does not exist or that permission is denied. Check the path and the
permissions.

Wrong:

```text
$ wolf check src/mian.wolf
error[E0001]: cannot read `src/mian.wolf`: no such file or directory
```

Fixed:

```text
$ wolf check src/main.wolf
```
