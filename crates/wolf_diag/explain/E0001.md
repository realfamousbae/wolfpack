# E0001: cannot read a file or directory

`wolf` could not read a file or a directory that the command needs: the file does not exist,
is not readable, or is larger than 4 GiB. The message names the path and the reason the operating
system gives.

Check the path and the permissions. Without paths, `wolf check`, `wolf build` and the other commands
work on the project around the current directory.

Wrong:

```text
$ wolf check src/mian.wolf
error[E0001]: cannot read `src/mian.wolf`: No such file or directory
```

Fixed:

```text
$ wolf check src/main.wolf
```
