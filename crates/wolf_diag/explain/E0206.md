# E0206: unknown section name

The name before `{` at the top level is not a section. The sections are `imports`, `extern`,
`config`, `types`, `interfaces`, `impl`, `functions` and `tests`; the names are plural.

Wrong:

```wolf wrong
module main

main {
    print("hi")
}

helper {
    fn twice(x: Int) -> Int {
        x * 2
    }
}
```

Fixed:

```wolf fixed
module main

main {
    print(twice(2).to_string())
}

functions {
    fn twice(x: Int) -> Int {
        x * 2
    }
}
```
