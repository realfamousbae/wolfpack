# E0206: unknown section name

A block at the top level has a name that is not a section. The sections are `imports`, `extern`,
`config`, `types`, `interfaces`, `impl`, `functions` and `tests`.

Wrong:

```wolf
module main

function {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print("hi")
    }
}
```
