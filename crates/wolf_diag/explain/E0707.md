# E0707: operation not available on an opaque type

An extern type is opaque: Wolfpack knows nothing about its contents, so it has no fields, methods,
`==` or `.copy()`, and cannot be a map key. It is used only through extern functions, which may take
it as their first parameter like a method.

Wrong:

```wolf wrong
module main

extern {
    go {
        type Regex from "*regexp.Regexp"
        fn compile(pattern: String) -> Regex from "regexp.MustCompile"
    }
}

functions {
    fn main() {
        let r = compile("a+")
        print(r.source)
    }
}
```

Fixed:

```wolf fixed
module main

extern {
    go {
        type Regex from "*regexp.Regexp"
        fn compile(pattern: String) -> Regex from "regexp.MustCompile"
        fn source(r: Regex) -> String from "(*regexp.Regexp).String"
    }
}

functions {
    fn main() {
        let r = compile("a+")
        print(source(r))
    }
}
```
