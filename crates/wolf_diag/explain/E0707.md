# E0707: operation not available on an opaque type

An opaque extern type has no fields, no methods, no `==`, no `.copy()` and cannot be a map key. It
is used only through extern functions that take or return it.

Wrong:

```wolf
module main

extern {
    go {
        type Regex from "*regexp.Regexp"
        fn compile(p: String) -> Regex from "regexp.MustCompile"
    }
}

functions {
    fn main() {
        let r = compile("a+")
        let _ = r.copy()
    }
}
```

Fixed:

```wolf
module main

extern {
    go {
        type Regex from "*regexp.Regexp"
        fn compile(p: String) -> Regex from "regexp.MustCompile"
        fn matches(r: Regex, s: String) -> Bool from "(*regexp.Regexp).MatchString"
    }
}

functions {
    fn main() {
        let r = compile("a+")
        print(matches(r, "aa").to_string())
    }
}
```
