# E0708: extern name declared twice in one target block

A target block declares the same extern name twice. Each name has one declaration per target; remove
the second one.

Wrong:

```wolf wrong
module main

extern {
    ts {
        fn now() -> Int from "Date.now"
        fn now() -> Int from "Date.now"
    }
}

main {
    print(now().to_string())
}
```

Fixed:

```wolf fixed
module main

extern {
    ts {
        fn now() -> Int from "Date.now"
    }
}

main {
    print(now().to_string())
}
```
