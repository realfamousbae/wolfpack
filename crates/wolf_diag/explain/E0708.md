# E0708: extern name declared twice in one target block

An extern name is declared twice in one target block. Remove one of the declarations.

Wrong:

```wolf
module main

extern {
    ts {
        fn now() -> Int from "Date.now"
        fn now() -> Int from "Date.now"
    }
}

functions {
    fn main() {
        print(now().to_string())
    }
}
```

Fixed:

```wolf
module main

extern {
    ts {
        fn now() -> Int from "Date.now"
    }
}

functions {
    fn main() {
        print(now().to_string())
    }
}
```
