# E0107: malformed number literal

A number literal does not follow the rules of chapter 1. Integers have no leading zeros (octal
numbers are written `0o7`), an `_` separator stands only between two digits, a prefix such as `0x`
needs at least one digit, a float has digits on both sides of `.` and after `e`, and type suffixes
such as `5i32` are reserved.

Wrong:

```wolf wrong
module main

config {
    mask: Int = 007
}

main {
    print(mask.to_string())
}
```

Fixed:

```wolf fixed
module main

config {
    mask: Int = 0o7
}

main {
    print(mask.to_string())
}
```
