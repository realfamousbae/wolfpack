# E0107: malformed number literal

A number literal is malformed: a `_` at the start or the end of the digits, two `_` in a row, a
`.` without digits after it, an exponent without digits, or digits that the base does not have,
such as `0b2`.

Wrong:

```wolf
module main

functions {
    fn main() {
        print((1__000).to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print((1_000).to_string())
    }
}
```
