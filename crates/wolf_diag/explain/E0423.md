# E0423: integer out of range or constant evaluation panic

An integer literal is outside the range of `Int` (from -9223372036854775808 to 9223372036854775807),
or computing a constant panics, for example on overflow, division by zero or a shift by 64 or more.
Constants are computed by the compiler, so such a panic is a compile error.

Wrong:

```wolf wrong
module main

config {
    max: Int = 9223372036854775807
    next: Int = max + 1
}

functions {
    fn main() {
        print(next.to_string())
    }
}
```

Fixed:

```wolf fixed
module main

config {
    max: Int = 9223372036854775807
    next: Int = max - 1
}

functions {
    fn main() {
        print(next.to_string())
    }
}
```
