# E0423: integer out of range or constant evaluation panic

An integer literal does not fit in `Int`, or evaluating a constant panics (an overflow, a division
by zero, a shift out of range). The compiler evaluates constants, so the error is found before the
program runs.

Wrong:

```wolf
module main

config {
    max: Int = 9223372036854775807
    too_big: Int = max + 1
}

functions {
    fn main() {
        print(too_big.to_string())
    }
}
```

Fixed:

```wolf
module main

config {
    max: Int = 9223372036854775807
    almost: Int = max - 1
}

functions {
    fn main() {
        print(almost.to_string())
    }
}
```
