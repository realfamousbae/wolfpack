# E0435: `break` with a value outside `loop`

Only a `loop` is an expression that ends with a value: `let x = loop { ... break value ... }`. A
`while` or a `for` may end without any `break`, so it has no value. Use `loop`, or keep the value
in a variable. The same holds for `break label: value`: the loop with that label must be a `loop`.

Wrong:

```wolf wrong
module main

main {
    var i = 0
    while i < 10 {
        i += 1
        if i * i > 20 {
            break i
        }
    }
}
```

Fixed:

```wolf fixed
module main

main {
    var i = 0
    let first = loop {
        i += 1
        if i * i > 20 {
            break i
        }
    }
    print(first.to_string())
}
```
