# E0415: two functions with the same name on one type

A type has two functions with the same name, in its inherent block or in two interface
implementations. Calls such as `x.name()` must name one function; rename one of them.

Wrong:

```wolf
module main

types {
    struct Box {
        n: Int
    }
}

impl {
    Box {
        fn get(self) -> Int { self.n }

        fn get(self) -> Int { self.n + 1 }
    }
}

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

types {
    struct Box {
        n: Int
    }
}

impl {
    Box {
        fn get(self) -> Int { self.n }

        fn next(self) -> Int { self.n + 1 }
    }
}

functions {
    fn main() {
        let b = Box { n: 1 }
        print((b.get() + b.next()).to_string())
    }
}
```
