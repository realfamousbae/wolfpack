# E0415: two functions with the same name on one type

A type has at most one function with a given name, across its inherent block and all its interface
implementations: method calls are written `value.name()` without saying which block is meant. Rename
one of them. The blocks for one instantiation of a generic type count too: `Stack<Int>` and
`Stack<String>` cannot both have a method `describe`.

Wrong:

```wolf wrong
module main

types {
    struct Job {
        name: String
    }
}

impl {
    Job {
        fn message(self) -> String {
            self.name.copy()
        }
    }

    Job: Error {
        fn message(self) -> String {
            "job " + self.name
        }
    }
}

main {
    let job = Job { name: "a" }
    print(job.message())
}
```

Fixed:

```wolf fixed
module main

types {
    struct Job {
        name: String
    }
}

impl {
    Job {
        fn label(self) -> String {
            self.name.copy()
        }
    }

    Job: Error {
        fn message(self) -> String {
            "job " + self.name
        }
    }
}

main {
    let job = Job { name: "a" }
    print(job.label() + job.message())
}
```
