# E0306: struct literal in a condition without parentheses

A struct literal is used directly in the condition of `if`, `while` or `match`, or in the
collection of `for`. Its `{` would be read as the start of the block. Put the literal in
parentheses.

Wrong:

```wolf
module main

types {
    struct P {
        x: Int
    }
}

functions {
    fn main() {
        let p = P { x: 1 }
        if p == P { x: 1 } {
            print("same")
        }
    }
}
```

Fixed:

```wolf
module main

types {
    struct P {
        x: Int
    }
}

functions {
    fn main() {
        let p = P { x: 1 }
        if p == (P { x: 1 }) {
            print("same")
        }
    }
}
```
