# E0432: method with the name of a field

A method of a struct, a function with `self` in its inherent block or in an interface
implementation, has the name of one of the struct's fields. TypeScript classes and Go structs keep
fields and methods in one namespace, so the two could not both exist in the generated code. Rename
the method or the field. Associated functions without `self` and the fields of enum variants may
share a name.

Wrong:

```wolf wrong
module main

types {
    struct Counter {
        label: String
        value: Int
    }
}

impl {
    Counter {
        fn label(self) -> String {
            self.label.to_upper_ascii()
        }
    }
}

main {
    let c = Counter { label: "clicks", value: 1 }
    print(c.label())
}
```

Fixed:

```wolf fixed
module main

types {
    struct Counter {
        name: String
        value: Int
    }
}

impl {
    Counter {
        fn label(self) -> String {
            self.name.to_upper_ascii()
        }
    }
}

main {
    let c = Counter { name: "clicks", value: 1 }
    print(c.label())
}
```
