# E0444: a method without a default called by its interface

`Named.greeting(x)` calls the default of `greeting`, the body that the interface `Named` gives
it, also when the type of `x` replaces it: an `override` can build on the default this way. A
method without a default has no such body, so it is called on a value instead: `x.name()`.

Wrong:

```wolf wrong
module main

types {
    struct Cat {
        nick: String
    }
}

interfaces {
    interface Named {
        fn name(self) -> String
    }
}

impl {
    Cat: Named {
        fn name(self) -> String {
            self.nick.copy()
        }
    }
}

main {
    let cat = Cat { nick: "Tom" }
    print(Named.name(cat))
}
```

Fixed:

```wolf fixed
module main

types {
    struct Cat {
        nick: String
    }
}

interfaces {
    interface Named {
        fn name(self) -> String
    }
}

impl {
    Cat: Named {
        fn name(self) -> String {
            self.nick.copy()
        }
    }
}

main {
    let cat = Cat { nick: "Tom" }
    print(cat.name())
}
```
