# E0302: unclosed delimiter

An opening `(`, `[` or `{` has no matching closing delimiter, or a closing one does not match
the innermost open one. The opening delimiter is shown.

Wrong:

```wolf
module main

functions {
    fn main() {
        print(("hi")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print(("hi"))
    }
}
```
