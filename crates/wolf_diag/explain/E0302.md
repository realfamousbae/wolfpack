# E0302: unclosed delimiter

An opening `(`, `[` or `{` has no matching closing delimiter. The message names the delimiter that
is missing; the error usually points at the place where the parser gave up, which may be a line
after the real mistake.

Wrong:

```wolf wrong
module main

functions {
    fn main() {
        print("a"
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn main() {
        print("a")
    }
}
```
