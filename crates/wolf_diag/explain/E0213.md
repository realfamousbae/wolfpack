# E0213: `main` is not the last function

In a program, `main` is the last function of the `functions` section of `src/main.wolf`, so the
entry point is always at the same place. Move it to the end of the section.

Wrong:

```wolf wrong
module main

functions {
    fn main() {
        print(greeting())
    }

    fn greeting() -> String {
        "hi"
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn greeting() -> String {
        "hi"
    }

    fn main() {
        print(greeting())
    }
}
```
