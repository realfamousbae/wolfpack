# E0213: `main` is not the last function

In the entry module, `main` is the last function of the `functions` section, so that a reader
finds it at the end.

Wrong:

```wolf
module main

functions {
    fn main() {
        print(greet())
    }

    fn greet() -> String { "hi" }
}
```

Fixed:

```wolf
module main

functions {
    fn greet() -> String { "hi" }

    fn main() {
        print(greet())
    }
}
```
