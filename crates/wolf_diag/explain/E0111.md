# E0111: non-ASCII character in an identifier

Names may contain only ASCII letters, digits and `_`. Each backend translates names to the naming
style of its target, and the targets do not agree on non-ASCII names. Non-ASCII text is fine inside
strings and comments.

Wrong:

```wolf wrong
module main

config {
    naïve: Int = 1
}

functions {
    fn main() {
        print(naïve.to_string())
    }
}
```

Fixed:

```wolf fixed
module main

config {
    naive: Int = 1
}

functions {
    fn main() {
        print(naive.to_string())
    }
}
```
