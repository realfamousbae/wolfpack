# E0111: non-ASCII character in an identifier

Identifiers use ASCII letters, digits and `_` only. A non-ASCII letter such as `é` or a Cyrillic
letter is not allowed in a name; it is allowed in strings and comments.

Wrong:

```wolf
module main

functions {
    fn main() {
        let café = 1
        print(café.to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let cafe = 1
        print(cafe.to_string())
    }
}
```
