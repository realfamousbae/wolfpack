# E0422: wrong fields in a struct literal or pattern

A struct literal gives every field exactly once and no other fields. A struct pattern names every
field too, or ends with `..` to ignore the rest.

Wrong:

```wolf wrong
module main

types {
    struct User {
        name: String
        age: Int
    }
}

functions {
    fn main() {
        let u = User { name: "ann" }
        print(u.name)
    }
}
```

Fixed:

```wolf fixed
module main

types {
    struct User {
        name: String
        age: Int
    }
}

functions {
    fn main() {
        let u = User { name: "ann", age: 30 }
        print(u.name)
    }
}
```
