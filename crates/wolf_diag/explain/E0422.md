# E0422: wrong fields in a struct literal or pattern

A struct literal or pattern names fields that the type does not have, or a literal misses some
fields. A literal gives every field exactly once; a pattern may leave fields out with `..`.

Wrong:

```wolf
module main

types {
    struct Point {
        x: Int
        y: Int
    }
}

functions {
    fn main() {
        let p = Point { x: 1 }
        print(p.x.to_string())
    }
}
```

Fixed:

```wolf
module main

types {
    struct Point {
        x: Int
        y: Int
    }
}

functions {
    fn main() {
        let p = Point { x: 1, y: 2 }
        print(p.x.to_string())
    }
}
```
