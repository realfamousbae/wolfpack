# E0433: refutable pattern in `let`

The pattern of a destructuring `let` must match every value of its type: a name, `_`, or a struct
pattern made of those. A pattern that can fail, such as `Some(x)` or a variant of an enum, needs
`if let` or `match`, which say what happens with the other values.

Wrong:

```wolf wrong
module main

main {
    let Some(at) = "wolf".find("l")
    print(at.to_string())
}
```

Fixed:

```wolf fixed
module main

main {
    if let Some(at) = "wolf".find("l") {
        print(at.to_string())
    }
}
```
