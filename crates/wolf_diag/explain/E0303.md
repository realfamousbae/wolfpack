# E0303: binary operator at the start of a line

Wolfpack has no `;`, so a line break ends a statement. A binary operator at the start of a line
would silently start a new statement, which is why it is rejected. When a long expression is broken,
the operator ends the first line.

Wrong:

```wolf wrong
module main

functions {
    fn total(price: Int, tax: Int) -> Int {
        let sum = price
            + tax
        sum
    }

    fn main() {
        print(total(2, 3).to_string())
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn total(price: Int, tax: Int) -> Int {
        let sum = price +
            tax
        sum
    }

    fn main() {
        print(total(2, 3).to_string())
    }
}
```
