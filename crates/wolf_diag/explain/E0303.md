# E0303: binary operator at the start of a line

A line starts with a binary operator. A new line ends a statement, so the operator would have no
left operand. Put the operator at the end of the previous line instead.

Wrong:

```wolf
module main

functions {
    fn main() {
        let total = 1
            + 2
        print(total.to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let total = 1 +
            2
        print(total.to_string())
    }
}
```
