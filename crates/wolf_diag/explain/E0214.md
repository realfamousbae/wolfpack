# E0214: `fn main` in `functions`

The entry point of a program is not a function. It is the `main` section, which stands above
`functions`. Its header may carry the command-line arguments and the result type, both optional:
`main(args: List<String>) -> Result<Void, Error> { ... }`. A function called `main` in `functions`
is an old way of writing the same thing; remove it, or move its body into the `main` section.

Wrong:

```wolf wrong
module main

main {
    print(greeting())
}

functions {
    fn greeting() -> String {
        "hi"
    }

    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf fixed
module main

main {
    print(greeting())
}

functions {
    fn greeting() -> String {
        "hi"
    }
}
```
