# E0806: target tool rejected the native code

The tool of the target, such as `tsc`, `go vet` or `cargo`, rejected the project, and the project
has code in `native/<target>/`. The note shows the message of the tool. Usually the error is in a
native file, or a function in `native/` does not match its `extern` declaration: a different name,
other parameter types or another result type. Correct the native file or the declaration. Unlike
E0802, this is not a bug in `wolf`.

Wrong:

```text
$ wolf run --target ts
error[E0806]: TypeScript rejected the code of `native/ts/`
  = note: src/native/slug.ts(2,10): error TS2322: Type 'number' is not assignable to type 'string'.
```

Fixed:

Correct `native/ts/slug.ts` so that `slugify` returns a `string`, as its declaration
`fn slugify(s: String) -> String` says.
