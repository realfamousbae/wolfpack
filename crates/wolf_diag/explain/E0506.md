# E0506: not a mutable place

A `mut` argument, the target of an assignment or the list of `for x in mut` must be a mutable
place: a `var` variable, a `mut` parameter, or a field or element of one. A function result is a
temporary value and cannot be changed.

Wrong:

```wolf
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn make() -> User {
        User { name: "ann", tags: ["admin"] }
    }

    fn rename(mut u: User) {
        u.name = "bob"
    }

    fn main() {
        rename(mut make())
    }
}
```

Fixed:

```wolf
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn make() -> User {
        User { name: "ann", tags: ["admin"] }
    }

    fn rename(mut u: User) {
        u.name = "bob"
    }

    fn main() {
        var u = make()
        rename(mut u)
        print(u.name)
    }
}
```
