# E0506: not a mutable place

A `mut` argument and the list of `for x in mut` must be a place that can change: a `var` variable, a
field or an element of one. The result of a call is a temporary value, so changing it would have no
effect. Store it in a `var` first.

Wrong:

```wolf wrong
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn change(mut u: User) {
        u.name = "changed"
    }

    fn make() -> User {
        User { name: "ann", tags: [] }
    }

    fn main() {
        change(mut make())
    }
}
```

Fixed:

```wolf fixed
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn change(mut u: User) {
        u.name = "changed"
    }

    fn make() -> User {
        User { name: "ann", tags: [] }
    }

    fn main() {
        var u = make()
        change(mut u)
        print(u.name)
    }
}
```
