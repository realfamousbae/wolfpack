# E0424: unknown field or method

A field or method is used that the type does not have. The message suggests a close name if there
is one. Methods of other modules must be `pub`.

Wrong:

```wolf
module main

functions {
    fn main() {
        let s = "hello"
        print(s.size().to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let s = "hello"
        print(s.len().to_string())
    }
}
```
