# E0424: unknown field or method

The type has no field or method with this name. The help may suggest a similar name. A method is
called with parentheses (`p.sum()`), and a function without `self` is called on the type
(`Point.origin()`), not on a value.

Wrong:

```wolf wrong
module main

types {
    struct Point {
        x: Int
        y: Int
    }
}

main {
    let p = Point { x: 1, y: 2 }
    print(p.z.to_string())
}
```

Fixed:

```wolf fixed
module main

types {
    struct Point {
        x: Int
        y: Int
    }
}

main {
    let p = Point { x: 1, y: 2 }
    print(p.y.to_string())
}
```
