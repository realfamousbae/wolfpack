# E0209: unknown or duplicate extern target block

An `extern` section has a block for an unknown target, or two blocks for the same target. The
targets are `ts`, `go` and `rust`, each at most once.

Wrong:

```wolf
module main

extern {
    js {
        fn now() -> Int from "Date.now"
    }
}

functions {
    fn main() {
        print(now().to_string())
    }
}
```

Fixed:

```wolf
module main

extern {
    ts {
        fn now() -> Int from "Date.now"
    }
}

functions {
    fn main() {
        print(now().to_string())
    }
}
```
