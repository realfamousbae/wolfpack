# E0209: unknown or duplicate extern target block

Inside `extern` each block is named after a target: `ts`, `go` or `rust`, and each target has at
most one block. The block names an unknown target or repeats one.

Wrong:

```wolf wrong
module main

extern {
    python {
        fn upper(s: String) -> String from "str.upper"
    }
}

functions {
    fn main() {
        print(upper("hi"))
    }
}
```

Fixed:

```wolf fixed
module main

extern {
    ts {
        fn upper(s: String) -> String from "String.prototype.toUpperCase"
    }
}

functions {
    fn main() {
        print(upper("hi"))
    }
}
```
