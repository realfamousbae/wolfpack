# E0611: invalid manifest

`wolfpack.toml` is not valid: it is not TOML, a key is unknown or missing, or a value is wrong. The
package name is `kebab-case`, the version has three parts (`0.1.0`), `kind` is `"cli"` or `"lib"`,
and the default target must be one of the enabled targets.

Wrong:

```wolf wrong
module main

main {
    print("hi")
}

// file: wolfpack.toml
[package]
name = "demo"
version = "1.0"
kind = "cli"
```

Fixed:

```wolf fixed
module main

main {
    print("hi")
}

// file: wolfpack.toml
[package]
name = "demo"
version = "1.0.0"
kind = "cli"
```
