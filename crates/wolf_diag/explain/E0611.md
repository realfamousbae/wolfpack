# E0611: invalid manifest

`wolfpack.toml` is not valid: a TOML syntax error, an unknown key, a missing `[package]` entry, a
name that is not kebab-case, or a target that is not enabled. The message points at the key.

Wrong:

```toml
[package]
name = "My App"
version = "0.1.0"
kind = "cli"
```

Fixed:

```toml
[package]
name = "my-app"
version = "0.1.0"
kind = "cli"
```
