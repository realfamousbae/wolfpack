# E0314: nesting too deep

Expressions, types or blocks are nested deeper than the parser allows (256 levels). Such code is
almost always generated; split it into smaller parts with local variables or functions.

Wrong:

A constant with more than 256 nested parentheses:

```text
    config {
        x: Int = ((((((((((...(1)...))))))))))
    }
```

Fixed:

```wolf fixed
module main

config {
    x: Int = 1
}

main {
    print(x.to_string())
}
```
