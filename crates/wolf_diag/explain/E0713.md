# E0713: name of a native module not available

The compiler reads the declarations of a native module and maps each one to wolfpack. An item it
cannot map is not available, and the message says why: for example a `&mut` parameter (extern code
cannot change wolfpack values), a type that wolfpack has no equivalent for, an `async` function, or
a name that is a keyword of wolfpack. Change the native code to use the forms of the type table of
`native modules` in the guide, or add a function that wraps it.

Wrong:

```wolf wrong
module main

imports {
    native.counter
}

main {
    print(counter.double([1, 2]).len().to_string())
}

// file: native/rust/counter.rs
pub fn double(v: &mut Vec<i64>) -> Vec<i64> {
    v.iter().map(|x| x * 2).collect()
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "cli"

[targets]
default = "rust"
```

Fixed:

```wolf fixed
module main

imports {
    native.counter
}

main {
    print(counter.double([1, 2]).len().to_string())
}

// file: native/rust/counter.rs
pub fn double(v: &[i64]) -> Vec<i64> {
    v.iter().map(|x| x * 2).collect()
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "cli"

[targets]
default = "rust"
```
