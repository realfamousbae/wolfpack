# E0602: unknown module in an import

An import names a module that does not exist. Modules of the project are the files under `src/`
(`src/users/model.wolf` is `users.model`); modules of the standard library start with `std.`.

Wrong:

```wolf
module main

imports {
    std.strings
}

functions {
    fn main() {
        print(string.join(["a"], ","))
    }
}
```

Fixed:

```wolf
module main

imports {
    std.string
}

functions {
    fn main() {
        print(string.join(["a"], ","))
    }
}
```
