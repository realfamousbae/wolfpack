# E0602: unknown module in an import

An import names a module that does not exist. Modules of the project are named after their path
under `src/` (`src/users/model.wolf` is `users.model`), and the standard library modules start with
`std.`. The help may suggest a similar name.

Wrong:

```wolf wrong
module main

imports {
    std.files
}

main {
    print(files.exists("a.txt").to_string())
}
```

Fixed:

```wolf fixed
module main

imports {
    std.fs
}

main {
    print(fs.exists("a.txt").to_string())
}
```
