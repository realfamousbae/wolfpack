# E0102: unexpected character

A character that cannot start any token. Wolfpack has no `;`: each statement stands on its own line.
Strings use double quotes, not `'`. Only spaces, tabs and line ends count as whitespace, so a
non-breaking space copied from a web page is an error too.

Wrong:

```wolf wrong
module main

config {
    limit: Int = 10;
}

functions {
    fn main() {
        print(limit.to_string())
    }
}
```

Fixed:

```wolf fixed
module main

config {
    limit: Int = 10
}

functions {
    fn main() {
        print(limit.to_string())
    }
}
```
