# E0102: unexpected character

A character that is not part of any token: Wolfpack has no `;`, `@`, `#` or `$` outside strings
and comments. Statements are separated by new lines, not by `;`.

Wrong:

```wolf
module main

functions {
    fn main() {
        print("a"); print("b")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print("a")
        print("b")
    }
}
```
