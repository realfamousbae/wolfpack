# E0609: unknown name

The name is not declared in this scope: not a local variable or parameter, not an item of the
module, not imported and not in the prelude. It may be misspelled, or come from a module that is not
imported.

Wrong:

```wolf wrong
module main

main {
    prnt("hi")
}
```

Fixed:

```wolf fixed
module main

main {
    print("hi")
}
```
