# E0609: unknown name

A name is not declared in this scope and not imported. The message suggests a close name if
there is one. Functions of other modules need an import.

Wrong:

```wolf
module main

functions {
    fn main() {
        let count = 3
        print(cuont.to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let count = 3
        print(count.to_string())
    }
}
```
