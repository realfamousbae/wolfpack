# E0613: invalid config override

A `[config.<module>]` table of `wolfpack.toml` overrides constants of that module at build time. The
module must exist, the constant must be declared in its `config` section, and the value must have
the type of the constant.

Wrong:

```wolf wrong
module main

config {
    port: Int = 80
}

main {
    print(port.to_string())
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "cli"

[config.main]
port = "8080"
```

Fixed:

```wolf fixed
module main

config {
    port: Int = 80
}

main {
    print(port.to_string())
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "cli"

[config.main]
port = 8080
```
