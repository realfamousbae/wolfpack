# E0803: target dependencies could not be fetched

The packages of `[extern.<target>.dependencies]` could not be fetched: `npm install` failed. The
output of npm is shown. Check the names and versions in `wolfpack.toml` and the network connection.

Wrong:

```toml
[extern.ts.dependencies]
"fastest-levenstein" = "^1.0.16"
```

Fixed:

```toml
[extern.ts.dependencies]
"fastest-levenshtein" = "^1.0.16"
```
