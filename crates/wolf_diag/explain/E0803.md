# E0803: target dependencies could not be fetched

The packages listed in `[extern.<target>.dependencies]` of `wolfpack.toml` could not be fetched, for
example with `npm install` for TypeScript. The note shows the message of the package manager. Check
the names and the versions, and the network connection.

Wrong:

In `wolfpack.toml`, a package name with a typo:

```toml
[extern.ts.dependencies]
"left-padd" = "^1.0.0"
```

Fixed:

The name of a package that exists:

```toml
[extern.ts.dependencies]
"left-pad" = "^1.3.0"
```
