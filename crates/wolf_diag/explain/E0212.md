# E0212: doc comment in a position where it documents nothing

A doc comment (`///` or `/** */`) is where it documents nothing, for example inside a function
body or at the end of a section. Doc comments come right before the declaration they describe; use
an ordinary comment (`//`) elsewhere.

Wrong:

```wolf
module main

functions {
    fn main() {
        /// The greeting.
        print("hi")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        // The greeting.
        print("hi")
    }
}
```
