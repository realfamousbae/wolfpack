# E0212: doc comment in a position where it documents nothing

A doc comment `///` documents the declaration that follows it: an item, a field, a variant or a
method. Here nothing that can be documented follows it, for example a section or a statement. Use
`//!` before the `module` line to document the module, and `//` for ordinary comments.

Wrong:

```wolf wrong
module main

/// Prints a greeting.
functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf fixed
//! Prints a greeting.
module main

functions {
    fn main() {
        print("hi")
    }
}
```
