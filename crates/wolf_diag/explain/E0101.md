# E0101: file is not valid UTF-8

Wolfpack source files must be encoded in UTF-8. The file contains bytes that are not UTF-8, usually
because an editor saved it in another encoding such as Windows-1252 or Latin-1. Save the file again
as UTF-8.

Wrong:

A file saved as Latin-1, where the `é` of `café` is the single byte 0xE9:

```text
    config {
        name: String = "caf<0xE9>"
    }
```

Fixed:

The same file saved as UTF-8, where `é` is the two bytes 0xC3 0xA9:

```text
    config {
        name: String = "café"
    }
```
