# E0614: missing `main` or wrong signature

A program needs `fn main()` in its entry module (and in every example), without parameters, not
`pub`, returning nothing or `Result<Void, E>`.

Wrong:

```wolf
module main

functions {
    fn start() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print("hi")
    }
}
```
