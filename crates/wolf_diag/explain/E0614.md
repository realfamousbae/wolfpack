# E0614: missing `main` or wrong signature

A program and every example under `examples/` need a function `main` in their `functions` section,
written `fn main()` or `fn main() -> Result<Void, Error>`. It takes no parameters and is not `pub`;
the arguments of the program come from `std.io.args()`.

Wrong:

```wolf wrong
module main

functions {
    fn main(args: List<String>) {
        print(args.len().to_string())
    }
}
```

Fixed:

```wolf fixed
module main

imports {
    std.io
}

functions {
    fn main() {
        print(io.args().len().to_string())
    }
}
```
