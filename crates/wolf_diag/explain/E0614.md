# E0614: missing `main` or wrong header

A program and every example under `examples/` need a `main` section. Its header may have the
parameter `args: List<String>` (the command-line arguments, without the program name) and the
result type `Result<Void, Error>`; both are optional. Any other parameter or result type is an
error, and so is a program without the section.

Wrong:

```wolf wrong
module main

main -> Int {
    0
}
```

Fixed:

```wolf fixed
module main

main(args: List<String>) -> Result<Void, Error> {
    print(args.len().to_string())
    Ok(())
}
```
