# E0002: invalid command-line usage

The command line of `wolf` is not valid: an unknown command or option, a missing argument, a value
that an option does not take, or a request the project cannot satisfy, such as running a library.
`wolf --help` and `wolf <command> --help` list what each command accepts.

Wrong:

```text
$ wolf run --target all
error[E0002]: `--target all` works only with `wolf build`; pass one target
```

Fixed:

```text
$ wolf run --target go
```
