# E0002: invalid command-line usage

The command line of `wolf` is not valid: an unknown command or option, a missing argument, a
value that the option does not take, or an option that does not apply here. For example
`--target all` is accepted by `wolf build` only, and `wolf run` on a library needs `--example`.
`wolf --help` and `wolf <command> --help` list what each command takes. The exit code is 2.

Wrong:

```text
$ wolf run --target all
```

Fixed:

```text
$ wolf build --target all
$ wolf run --target go
```
