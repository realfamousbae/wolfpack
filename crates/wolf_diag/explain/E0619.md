# E0619: section not allowed in a module of `tests/`

A module under `tests/` holds only tests, their helpers and imports: sections `imports`,
`functions` and `tests`. Types and implementations belong in `src/`.

Wrong:

```text
// tests/math.wolf
module tests.math

types {
    struct Fixture {
        n: Int
    }
}
```

Fixed:

```text
// tests/math.wolf
module tests.math

functions {
    fn fixture() -> Int { 1 }
}
```
