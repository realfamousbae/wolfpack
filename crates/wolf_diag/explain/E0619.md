# E0619: section not allowed in a module of `tests/`

Modules under `tests/` are integration tests: they test the project through its public API, so they
contain only `imports`, `functions` and `tests`. Move other declarations into a module of `src/`.

Wrong:

```wolf wrong
module main

main {
    print("hi")
}

// file: tests/flow.wolf
module tests.flow

types {
    struct Fixture {
        x: Int
    }
}

tests {
    test "works" {
        let f = Fixture { x: 1 }
        assert(f.x == 1)
    }
}
```

Fixed:

```wolf fixed
module main

main {
    print("hi")
}

// file: tests/flow.wolf
module tests.flow

functions {
    fn fixture() -> Int {
        1
    }
}

tests {
    test "works" {
        assert(fixture() == 1)
    }
}
```
