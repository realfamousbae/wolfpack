# E0416: interface is not object-safe

An interface used as a type, as in `List<Comparable>`, holds values of different types. That works
only if each method can be called without knowing the type, so no method may mention `Self` outside
its receiver: `compare(self, other: Self)` needs two values of one type. Use the interface as a
bound of a type parameter instead.

Wrong:

```wolf wrong
module main

main {
    print(count([1, 2]).to_string())
}

functions {
    fn count(items: List<Comparable>) -> Int {
        items.len()
    }
}
```

Fixed:

```wolf fixed
module main

main {
    print(count([1, 2]).to_string())
}

functions {
    fn count<T: Comparable>(items: List<T>) -> Int {
        items.len()
    }
}
```
