# E0416: interface is not object-safe

An interface whose methods mention `Self` other than as the receiver, such as `Comparable`, cannot
be the type of a value: two values of it could hold different types. Use it as a bound of a type
parameter instead.

Wrong:

```wolf
module main

functions {
    fn count(items: List<Comparable>) -> Int { items.len() }

    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn count<T: Comparable>(items: List<T>) -> Int { items.len() }

    fn main() {
        print(count([1, 2]).to_string())
    }
}
```
