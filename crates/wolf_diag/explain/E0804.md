# E0804: a tool could not be installed

`wolf setup` could not download or install a tool of a target: Node.js, TypeScript, Go or Rust. The
message says which tool and why, and the note shows the address it was downloading. Usually the
network is down or a proxy blocks the download; a download whose SHA-256 sum does not match is
rejected too. Nothing half-installed is kept, so it is safe to run `wolf setup` again. Without
`wolf setup`, install the tools yourself: `wolf` also finds them on `PATH`.

Wrong:

```text
$ wolf setup
installing Go 1.27.2
error[E0804]: Go could not be installed: io: Connection refused
  = note: downloading https://go.dev/dl/go1.27.2.darwin-arm64.tar.gz
  = help: check the network connection and run `wolf setup` again
```

Fixed:

```text
$ wolf setup
installing Go 1.27.2
  downloaded 76.4 MB
installed Go 1.27.2
```
