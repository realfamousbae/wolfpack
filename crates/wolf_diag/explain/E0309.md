# E0309: misplaced `self` parameter

`self` is allowed only as the first parameter of a method in an `impl` block or an interface. It
cannot appear later in the list, or in a free function.

Wrong:

```wolf wrong
module main

types {
    struct Counter {
        value: Int
    }
}

impl {
    Counter {
        fn add(amount: Int, mut self) {
            self.value += amount
        }
    }
}

main {
    var c = Counter { value: 1 }
    c.add(2)
    print(c.value.to_string())
}
```

Fixed:

```wolf fixed
module main

types {
    struct Counter {
        value: Int
    }
}

impl {
    Counter {
        fn add(mut self, amount: Int) {
            self.value += amount
        }
    }
}

main {
    var c = Counter { value: 1 }
    c.add(2)
    print(c.value.to_string())
}
```
