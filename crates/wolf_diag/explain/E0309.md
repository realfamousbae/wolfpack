# E0309: misplaced `self` parameter

`self` is allowed only as the first parameter of a method in an `impl` block or an interface.

Wrong:

```wolf
module main

functions {
    fn show(n: Int, self) -> String { n.to_string() }

    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn show(n: Int) -> String { n.to_string() }

    fn main() {
        print(show(1))
    }
}
```
