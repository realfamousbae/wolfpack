# E0508: overlapping places in one call

While a call changes or moves a place, the same call cannot use that place, or a part of it, in
another argument: the function would see the value change under it. Pass a copy of one argument, or
make two calls.

Wrong:

```wolf wrong
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn merge(mut into: List<String>, from: List<String>) {
        for f in from {
            into.push(f.copy())
        }
    }

    fn main() {
        var u = User { name: "ann", tags: ["a"] }
        merge(mut u.tags, u.tags)
        print(u.tags.len().to_string())
    }
}
```

Fixed:

```wolf fixed
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn merge(mut into: List<String>, from: List<String>) {
        for f in from {
            into.push(f.copy())
        }
    }

    fn main() {
        var u = User { name: "ann", tags: ["a"] }
        let more = u.tags.copy()
        merge(mut u.tags, more)
        print(u.tags.len().to_string())
    }
}
```
