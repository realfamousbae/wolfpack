# E0508: overlapping places in one call

Two arguments of one call refer to the same place, or to a place and a part of it, and at least
one of them is `mut` or `own`. The function could change a value that it also reads. Pass a copy for
one of them.

Wrong:

```wolf
module main

functions {
    fn merge(mut into: List<Int>, from: List<Int>) {
        for x in from {
            into.push(x)
        }
    }

    fn main() {
        var a = [1]
        merge(mut a, a)
        print(a.len().to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn merge(mut into: List<Int>, from: List<Int>) {
        for x in from {
            into.push(x)
        }
    }

    fn main() {
        var a = [1]
        merge(mut a, a.copy())
        print(a.len().to_string())
    }
}
```
