# E0211: duplicate test name

Two tests of one module have the same name. Test names identify tests in the report of `wolf test`
and in its filter, so they are unique per module.

Wrong:

```wolf
module main

functions {
    fn main() {
        print("hi")
    }
}

tests {
    test "adds" {
        assert(1 + 1 == 2)
    }

    test "adds" {
        assert(2 + 2 == 4)
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print("hi")
    }
}

tests {
    test "adds one and one" {
        assert(1 + 1 == 2)
    }

    test "adds two and two" {
        assert(2 + 2 == 4)
    }
}
```
