# E0211: duplicate test name

Two tests in one module have the same name. `wolf test` reports tests and filters them by name, so
the names must be unique within a module. Rename one of them.

Wrong:

```wolf wrong
module main

main {
    print("hi")
}

tests {
    test "adds" {
        assert(1 + 1 == 2)
    }

    test "adds" {
        assert(2 + 2 == 4)
    }
}
```

Fixed:

```wolf fixed
module main

main {
    print("hi")
}

tests {
    test "adds one" {
        assert(1 + 1 == 2)
    }

    test "adds two" {
        assert(2 + 2 == 4)
    }
}
```
