# E0511: change of a captured value

A closure changes a variable that it captures. Closures read the values they capture; to compute
a total, use a loop or return the new value from the closure.

Wrong:

```wolf
module main

functions {
    fn main() {
        var total = 0
        let add = |n: Int| {
            total += n
        }
        add(1)
        print(total.to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        var total = 0
        for n in [1, 2] {
            total += n
        }
        print(total.to_string())
    }
}
```
