# E0511: change of a captured value

A closure holds its own copy of each captured value, so changing a captured value inside the closure
would change only that copy, not the variable outside. This is not allowed. Return the new value
from the closure instead, or use a loop.

Wrong:

```wolf wrong
module main

functions {
    fn main() {
        var total = 0
        let add = |n: Int| {
            total += n
        }
        add(1)
        print(total.to_string())
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn main() {
        var total = 0
        let add = |a: Int, n: Int| a + n
        total = add(total, 1)
        print(total.to_string())
    }
}
```
