# E0701: `intrinsic` outside `std`

`intrinsic` marks declarations that the compiler implements itself; it is reserved for the standard
library. Give the function a body, or declare code of the target language in an `extern` section.

Wrong:

```wolf wrong
module main

functions {
    intrinsic fn twice(n: Int) -> Int

    fn main() {
        print(twice(2).to_string())
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn twice(n: Int) -> Int {
        n * 2
    }

    fn main() {
        print(twice(2).to_string())
    }
}
```
