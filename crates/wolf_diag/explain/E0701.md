# E0701: `intrinsic` outside `std`

`intrinsic` functions and types are implemented by the compiler for each target; only the standard
library declares them. Give the function a body, or use `extern` for code of a target language.

Wrong:

```wolf
module main

functions {
    intrinsic fn fast() -> Int

    fn main() {
        print(fast().to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn fast() -> Int { 1 }

    fn main() {
        print(fast().to_string())
    }
}
```
