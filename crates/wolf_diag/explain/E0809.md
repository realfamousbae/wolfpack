# E0809: bytecode file cannot be run

`wolf run <file>` runs a bytecode file that `wolf build --vm` wrote. The bytecode is not stable:
it can change in any release, so a file runs only with the version of `wolf` that built it, which
its first line names. A file of another version, a file that is not a bytecode file, and a file
that was damaged after it was built (cut short or changed: a checksum of its contents is checked
before it runs) run nothing. The message names the versions it knows. Build the file again with
the `wolf` that runs it, in the project of the program.

Wrong:

```text
$ wolf run hello.wbc
error[E0809]: `hello.wbc` was built by wolf 0.6.0, and this is wolf 0.7.0
 = help: build it again with this `wolf`: `wolf build --vm`
 = note: a bytecode file runs only with the version of `wolf` that built it
```

Fixed:

```text
$ cd hello
$ wolf build --vm
$ wolf run out/vm/hello.wbc
Hello, wolfpack!
```
