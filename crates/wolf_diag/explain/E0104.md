# E0104: unknown escape sequence

A backslash in a string is followed by a character that is not an escape. The escapes are `\n`,
`\r`, `\t`, `\0`, `\\`, `\"` and `\u{...}`. Write `\\` for a backslash.

Wrong:

```wolf
module main

functions {
    fn main() {
        print("C:\path")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print("C:\\path")
    }
}
```
