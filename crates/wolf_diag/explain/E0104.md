# E0104: unknown escape sequence

After `\` inside a string only these escapes are allowed: `\n`, `\r`, `\t`, `\0`, `\\`, `\"`, `\xHH`
and `\u{...}`. To write a backslash itself, double it.

Wrong:

```wolf wrong
module main

config {
    path: String = "C:\Users\wolf"
}

main {
    print(path)
}
```

Fixed:

```wolf fixed
module main

config {
    path: String = "C:\\Users\\wolf"
}

main {
    print(path)
}
```
