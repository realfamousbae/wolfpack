# E0004: no `wolfpack.toml` found

Commands that work on a project look for `wolfpack.toml` in the current directory and its parents.
None was found. Run the command inside a project, create one with `wolf new <name>`, or name the
files to check: `wolf check file.wolf` lexes and parses single files without a project.

Wrong:

```text
$ cd /tmp
$ wolf build
```

Fixed:

```text
$ wolf new hello
$ cd hello
$ wolf build
```
