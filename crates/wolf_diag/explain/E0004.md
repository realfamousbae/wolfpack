# E0004: no `wolfpack.toml` found

Commands that work on a project look for `wolfpack.toml` in the current directory and then in its
parents. None of them has one, so there is no project. Run the command inside a project, or create
one with `wolf new`.

Wrong:

```text
$ cd ~
$ wolf build
error[E0004]: no `wolfpack.toml` found
```

Fixed:

```text
$ wolf new hello
$ cd hello
$ wolf build
```
