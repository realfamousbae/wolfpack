# E0426: not a constant expression

A constant is computed by the compiler, so its value may use literals, other constants and
operators, but no function or method calls.

Wrong:

```wolf wrong
module main

config {
    width: Int = "abcd".len()
}

functions {
    fn main() {
        print(width.to_string())
    }
}
```

Fixed:

```wolf fixed
module main

config {
    width: Int = 4
}

functions {
    fn main() {
        print(width.to_string())
    }
}
```
