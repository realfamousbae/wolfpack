# E0426: not a constant expression

A constant in `config` must be computed by the compiler: literals, other constants, arithmetic and
comparisons. Calls of functions and methods are not constant.

Wrong:

```wolf
module main

config {
    width: Int = "abc".len()
}

functions {
    fn main() {
        print(width.to_string())
    }
}
```

Fixed:

```wolf
module main

config {
    width: Int = 3
}

functions {
    fn main() {
        print(width.to_string())
    }
}
```
