# E0316: `..base` not at the end of a struct literal

The update syntax `..base` gives the fields that a struct literal does not list. It comes last,
after every listed field, and only once.

Wrong:

```wolf wrong
module main

types {
    struct Size {
        w: Int
        h: Int
    }
}

main {
    let a = Size { w: 1, h: 2 }
    let b = Size { ..a, w: 3 }
    print(b.w.to_string())
}
```

Fixed:

```wolf fixed
module main

types {
    struct Size {
        w: Int
        h: Int
    }
}

main {
    let a = Size { w: 1, h: 2 }
    let b = Size { w: 3, ..a }
    print(b.w.to_string())
}
```
