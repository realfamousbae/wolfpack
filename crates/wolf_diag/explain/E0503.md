# E0503: move out of a field or an element

Only whole variables can be moved. A field or a list element cannot be moved out of its value,
because the rest would be left incomplete. Copy it, take the value apart with `match own`, or swap
in a new value with `replace(mut x.field, new)`.

Wrong:

```wolf
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn make() -> User {
        User { name: "ann", tags: ["admin"] }
    }

    fn keep(own s: String) -> Int { s.len() }

    fn main() {
        let u = make()
        print(keep(own u.name).to_string())
    }
}
```

Fixed:

```wolf
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn make() -> User {
        User { name: "ann", tags: ["admin"] }
    }

    fn keep(own s: String) -> Int { s.len() }

    fn main() {
        let u = make()
        print(keep(u.name.copy()).to_string())
    }
}
```
