# E0503: move out of a field or an element

A field or a list element cannot be moved out on its own: the struct or list would be left with a
hole. Copy it, take the whole value apart with `match own`, or swap a new value in with
`replace(mut place, new)`.

Wrong:

```wolf wrong
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

main {
    let u = User { name: "ann", tags: ["a"] }
    let tags = u.tags
    print(tags.len().to_string())
}
```

Fixed:

```wolf fixed
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

main {
    let u = User { name: "ann", tags: ["a"] }
    let tags = u.tags.copy()
    print(tags.len().to_string())
}
```
