# E0401: type mismatch

A value has a different type than the place it goes to: a `let` with a type, an argument, a field, a
function result, the branches of an `if` or the arms of a `match`, or a condition, which must be a
`Bool`. There are no implicit conversions; convert explicitly, for example with `to_string()`,
`to_float()` or `to_int()`.

Wrong:

```wolf wrong
module main

main {
    print(label(1))
}

functions {
    fn label(n: Int) -> String {
        if n > 10 { "big" } else { n }
    }
}
```

Fixed:

```wolf fixed
module main

main {
    print(label(1))
}

functions {
    fn label(n: Int) -> String {
        if n > 10 { "big" } else { n.to_string() }
    }
}
```
