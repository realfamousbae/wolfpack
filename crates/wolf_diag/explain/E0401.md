# E0401: type mismatch

A value has a different type than the place where it is used: an argument, the initializer of a
`let` with a written type, a return value, a condition, a branch of `if` or `match`. There are no
implicit conversions between types; convert explicitly, for example with `.to_string()`,
`.to_float()` or `.to_int()`.

Wrong:

```wolf
module main

functions {
    fn main() {
        let n: Int = "5"
        print(n.to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let n: Int = 5
        print(n.to_string())
    }
}
```
