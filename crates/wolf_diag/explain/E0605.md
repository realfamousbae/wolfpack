# E0605: name declared or imported twice in a module

A module declares or imports one name twice, or a struct declares a field twice. Rename one of
them, or import with `as`: `std.list.{range as numbers}`.

Wrong:

```wolf
module main

functions {
    fn size() -> Int { 1 }

    fn size() -> Int { 2 }

    fn main() {
        print(size().to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn size() -> Int { 1 }

    fn double_size() -> Int { 2 }

    fn main() {
        print((size() + double_size()).to_string())
    }
}
```
