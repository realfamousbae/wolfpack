# E0605: name declared or imported twice in a module

One module declares or imports the same name twice, for example a function with the name of an
imported function or two fields with one name. Every name in a module refers to one thing. Rename
one of them, or import with `as`: `std.list.{sum as list_sum}`.

Wrong:

```wolf wrong
module main

imports {
    std.list.{sum}
}

main {
    print(sum(1, 2).to_string())
}

functions {
    fn sum(a: Int, b: Int) -> Int {
        a + b
    }
}
```

Fixed:

```wolf fixed
module main

imports {
    std.list.{sum as list_sum}
}

main {
    print((sum(1, 2) + list_sum([3])).to_string())
}

functions {
    fn sum(a: Int, b: Int) -> Int {
        a + b
    }
}
```
