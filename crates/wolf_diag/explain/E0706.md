# E0706: generic extern function or `mut` parameter

Extern functions are not generic and have no `self` or `mut` parameters: extern code cannot change
Wolfpack values. Declare one function per type, and return a new value instead of changing one.

Wrong:

```wolf
module main

extern {
    ts {
        fn first<T>(items: List<T>) -> Int from "lib#first"
    }
}

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

extern {
    ts {
        fn first(items: List<Int>) -> Int from "lib#first"
    }
}

functions {
    fn main() {
        print("hi")
    }
}
```
