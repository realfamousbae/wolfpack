# E0706: generic extern function or `mut` parameter

Extern functions are not generic, since each target would need its own instance; declare one
function per type. They also take no `mut` parameters, because extern code cannot change Wolfpack
values; return the new value instead.

Wrong:

```wolf wrong
module main

extern {
    ts {
        fn push(mut items: List<Int>, n: Int) from "lib#push"
    }
}

functions {
    fn main() {
        var items = [1]
        push(mut items, 2)
        print(items.len().to_string())
    }
}
```

Fixed:

```wolf fixed
module main

extern {
    ts {
        fn pushed(items: List<Int>, n: Int) -> List<Int> from "lib#pushed"
    }
}

functions {
    fn main() {
        let items = pushed([1], 2)
        print(items.len().to_string())
    }
}
```
