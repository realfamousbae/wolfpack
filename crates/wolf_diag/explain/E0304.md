# E0304: `else` on a new line

`else` continues an `if`, so it is written on the line of the closing `}`: `} else {`. On a new line
it would start a new statement.

Wrong:

```wolf wrong
module main

functions {
    fn sign(x: Int) -> Int {
        if x < 0 {
            return -1
        }
        else {
            return 1
        }
    }

    fn main() {
        print(sign(5).to_string())
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn sign(x: Int) -> Int {
        if x < 0 {
            return -1
        } else {
            return 1
        }
    }

    fn main() {
        print(sign(5).to_string())
    }
}
```
