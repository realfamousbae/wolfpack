# E0304: `else` on a new line

`else` is on a new line after the `}` of an `if`. The new line ends the `if` statement, so `else`
has nothing to belong to. Write `} else {` on one line.

Wrong:

```wolf
module main

functions {
    fn main() {
        if true {
            print("yes")
        }
        else {
            print("no")
        }
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        if true {
            print("yes")
        } else {
            print("no")
        }
    }
}
```
