# E0204: empty section or extern block

A section or an `extern` target block is empty. An empty section is not written at all.

Wrong:

```wolf
module main

types {
}

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print("hi")
    }
}
```
