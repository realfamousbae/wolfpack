# E0204: empty section or extern block

A section, or a target block inside `extern`, has no entries. Empty sections are not written: remove
it.

Wrong:

```wolf wrong
module main

types {
}

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn main() {
        print("hi")
    }
}
```
