# E0441: a format specification that the type cannot take

A precision (`{x:.2}`) is only for a `Float`, and `0` (`{n:05}`) only for an `Int` or a `Float`.
For other types a width and an alignment still work: `{name:>10}`. Convert an `Int` with
`to_float()` to write it with a precision, and pad other values with the fill character `0`
(`{code:0>5}`) instead of `0`.

Wrong:

```wolf wrong
module main

main {
    let count = 3
    print(f"{count:.2}")
}
```

Fixed:

```wolf fixed
module main

main {
    let count = 3
    print(f"{count.to_float():.2}")
}
```
