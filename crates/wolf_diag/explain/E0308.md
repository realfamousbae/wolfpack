# E0308: assignment used as an expression or to a non-place

An assignment is a statement, not an expression: it cannot be used as a value, and its left side
must be a place (a variable, a field or an element).

Wrong:

```wolf
module main

functions {
    fn main() {
        var a = 1
        print((a = 2).to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        var a = 1
        a = 2
        print(a.to_string())
    }
}
```
