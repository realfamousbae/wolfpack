# E0308: assignment used as an expression or to a non-place

An assignment is a statement, not an expression: it has no value and cannot be chained or used
inside another expression. Its left side must be a place: a variable, `self`, a field or an index,
like `user.name` or `items[i]`.

Wrong:

```wolf wrong
module main

functions {
    fn main() {
        var a = 1
        var b = 2
        a = b = 3
        print((a + b).to_string())
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn main() {
        var a = 1
        var b = 2
        b = 3
        a = b
        print((a + b).to_string())
    }
}
```
