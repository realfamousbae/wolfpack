# E0437: label that is also a variable

After `break`, a name is a label when an enclosing loop has it, and a value otherwise. When the
name is both a label and a variable, the reader cannot tell which one is meant, so it is an error.
Rename the label or the variable.

Wrong:

```wolf wrong
module main

main {
    let limit = 3
    limit: for i in 0..limit {
        if i == 1 {
            break limit
        }
    }
}
```

Fixed:

```wolf fixed
module main

main {
    let limit = 3
    search: for i in 0..limit {
        if i == 1 {
            break search
        }
    }
}
```
