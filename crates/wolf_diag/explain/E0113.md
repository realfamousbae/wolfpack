# E0113: reserved literal prefix

A letter written directly before a string, such as `f"..."` or `r"..."`, is reserved for future
literal forms: string interpolation and raw strings. Remove the prefix, or put a space after the
letter if a name was meant.

Wrong:

```wolf wrong
module main

config {
    name: String = r"raw"
}

main {
    print(name)
}
```

Fixed:

```wolf fixed
module main

config {
    name: String = "raw"
}

main {
    print(name)
}
```
