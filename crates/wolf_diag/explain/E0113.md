# E0113: reserved literal prefix

A name directly followed by a string, such as `r"..."` or `b"..."`, is reserved for literal
kinds that a later version may add. Put a space or an operator between them.

Wrong:

```wolf
module main

functions {
    fn main() {
        print(r"raw")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print("raw")
    }
}
```
