# E0113: reserved literal prefix

A letter or a name written directly before a string is a literal prefix. Only `f` (an
interpolated string) and `r` (a raw string) exist; any other prefix, such as `b"..."`, is reserved
for future literal forms, and `fr"..."` does not exist because a raw string has no interpolation.
Remove the prefix, or put a space after the name if a name was meant.

Wrong:

```wolf wrong
module main

config {
    name: String = b"raw"
}

main {
    print(name)
}
```

Fixed:

```wolf fixed
module main

config {
    name: String = "raw"
}

main {
    print(name)
}
```
