# E0420: cannot infer the type

The type of a `let` or `var` comes from its value. An empty list `[]`, an empty map `[:]` or `None`
says nothing about the element type, and nothing later in the function fixes it, so the compiler
cannot choose one. Write the type after the name.

Wrong:

```wolf wrong
module main

functions {
    fn main() {
        var names = []
        print(names.len().to_string())
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn main() {
        var names: List<String> = []
        print(names.len().to_string())
    }
}
```
