# E0420: type cannot be inferred

The type of a variable cannot be inferred: an empty list `[]`, an empty map `[:]` or `None` with
nothing that says the element type. Write the type.

Wrong:

```wolf
module main

functions {
    fn main() {
        var names = []
        print(names.len().to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        var names: List<String> = []
        names.push("ann")
        print(names.len().to_string())
    }
}
```
