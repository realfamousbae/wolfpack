# E0603: imported name does not exist or is not public

An import group names something that the module does not declare, or does not declare `pub`.

Wrong:

```wolf
module main

imports {
    std.list.{total}
}

functions {
    fn main() {
        print(total([1]).to_string())
    }
}
```

Fixed:

```wolf
module main

imports {
    std.list.{sum}
}

functions {
    fn main() {
        print(sum([1]).to_string())
    }
}
```
