# E0603: imported name does not exist or is not public

A name in `imports { module.{Name} }` is not declared in that module, or it is declared without
`pub` and so is private to it. Check the spelling, or mark the declaration `pub`.

Wrong:

```wolf wrong
module main

imports {
    users.{greet}
}

functions {
    fn main() {
        print(greet())
    }
}

// file: src/users.wolf
module users

functions {
    fn greet() -> String {
        "hi"
    }
}
```

Fixed:

```wolf fixed
module main

imports {
    users.{greet}
}

functions {
    fn main() {
        print(greet())
    }
}

// file: src/users.wolf
module users

functions {
    pub fn greet() -> String {
        "hi"
    }
}
```
