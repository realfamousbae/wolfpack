# E0703: different signatures for one extern name

A program written against an extern name must work on every target, so each target block declares
the name with the same parameter and result types. Only the path after `from` differs.

Wrong:

```wolf wrong
module main

extern {
    ts {
        fn upper(s: String) -> String from "String.prototype.toUpperCase"
    }
    go {
        fn upper(s: String) -> Int from "strings.Count"
    }
}

main {
    print(upper("a"))
}
```

Fixed:

```wolf fixed
module main

extern {
    ts {
        fn upper(s: String) -> String from "String.prototype.toUpperCase"
    }
    go {
        fn upper(s: String) -> String from "strings.ToUpper"
    }
}

main {
    print(upper("a"))
}
```
