# E0703: different signatures for one extern name

An extern name is declared in several target blocks with different signatures. The rest of the
module calls one function, so every target declares the same parameter and result types.

Wrong:

```wolf
module main

extern {
    ts {
        fn upper(s: String) -> String from "String.prototype.toUpperCase"
    }
    go {
        fn upper(s: String) -> Int from "strings.ToUpper"
    }
}

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

extern {
    ts {
        fn upper(s: String) -> String from "String.prototype.toUpperCase"
    }
    go {
        fn upper(s: String) -> String from "strings.ToUpper"
    }
}

functions {
    fn main() {
        print(upper("hi"))
    }
}
```
