# E0447: a method that a super-interface has too

A type that implements an interface implements its super-interfaces too, and a type has at most
one method with a given name. So a method of an interface cannot have the name of a method of
one of its super-interfaces: the interface already has that method through the super-interface.

Wrong:

```wolf wrong
module main

interfaces {
    interface Named {
        fn name(self) -> String
    }

    interface Greeter: Named {
        fn name(self) -> String
        fn greeting(self) -> String
    }
}

main {
    print("ok")
}
```

Fixed:

```wolf fixed
module main

interfaces {
    interface Named {
        fn name(self) -> String
    }

    interface Greeter: Named {
        fn greeting(self) -> String
    }
}

main {
    print("ok")
}
```
