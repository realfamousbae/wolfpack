# E0201: the file does not start with `module`

Every source file starts with one `module` line that names the module, such as `module main` or
`module users.storage`; only comments may come before it. The line is missing, or a second `module`
line appears later in the file.

Wrong:

```wolf wrong
main {
    print("hi")
}
```

Fixed:

```wolf fixed
module main

main {
    print("hi")
}
```
