# E0201: the file does not start with `module`

Every source file starts with `module <path>`, after optional `//!` documentation. The path is the
file path under `src/` with `.` instead of `/` (`src/users/storage.wolf` is `module users.storage`);
`src/main.wolf` is `module main`.

Wrong:

```wolf
functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print("hi")
    }
}
```
