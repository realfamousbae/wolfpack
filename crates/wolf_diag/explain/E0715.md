# E0715: native targets disagree on a signature

A native module may have code for several targets: `native/rust/<path>.rs`, the Go package
`native/go/<path>/` and `native/ts/<path>.ts`. A function that both declare must map to the same wolfpack signature in each,
so that a call means the same on every target (a TypeScript `number` first takes `Int` where another target has an integer). A struct that both declare as a record must have
the same fields, in the same order and of the same types, and a struct that is a record in one
target cannot be an opaque type in the other. Here Rust takes a string and Go an integer.

Wrong:

```wolf wrong
module main

imports {
    native.calc
}

main {
    print(calc.twice(2).to_string())
}

// file: native/rust/calc.rs
pub fn twice(n: i64) -> i64 {
    n * 2
}

// file: native/go/calc/calc.go
package calc

func Twice(s string) int64 {
	return int64(len(s)) * 2
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "cli"

[targets]
default = "rust"
```

Fixed:

```wolf fixed
module main

imports {
    native.calc
}

main {
    print(calc.twice(2).to_string())
}

// file: native/rust/calc.rs
pub fn twice(n: i64) -> i64 {
    n * 2
}

// file: native/go/calc/calc.go
package calc

func Twice(n int64) int64 {
	return n * 2
}

// file: wolfpack.toml
[package]
name = "demo"
version = "0.1.0"
kind = "cli"

[targets]
default = "rust"
```
