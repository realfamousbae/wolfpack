# E0617: redeclaration of a prelude name

The prelude names, such as `Option`, `Result`, `List`, `print` and `assert`, are available in every
module, and a module cannot declare its own item with one of these names. Choose another name.

Wrong:

```wolf wrong
module main

main {
    print("hi")
}

functions {
    fn print(s: String) {
        assert(s.is_empty())
    }
}
```

Fixed:

```wolf fixed
module main

main {
    check_empty("")
}

functions {
    fn check_empty(s: String) {
        assert(s.is_empty())
    }
}
```
