# E0617: redeclaration of a prelude name

A declaration has the name of a prelude item such as `Option`, `Result`, `print` or `assert`, which
every module sees. Choose another name.

Wrong:

```wolf
module main

functions {
    fn print(s: String) {
        assert(s.is_empty())
    }

    fn main() {
        print("")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn check_empty(s: String) {
        assert(s.is_empty())
    }

    fn main() {
        check_empty("")
    }
}
```
