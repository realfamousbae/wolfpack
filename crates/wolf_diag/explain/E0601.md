# E0601: name does not follow the naming style

Names follow one style: types, variants and interfaces in `PascalCase`; functions, variables,
fields, parameters and modules in `snake_case`; constants in `snake_case` too. The style keeps the
generated code idiomatic in every target.

Wrong:

```wolf
module main

functions {
    fn PrintAll() {
        print("all")
    }

    fn main() {
        PrintAll()
    }
}
```

Fixed:

```wolf
module main

functions {
    fn print_all() {
        print("all")
    }

    fn main() {
        print_all()
    }
}
```
