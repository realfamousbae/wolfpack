# E0601: name does not follow the naming style

Names follow one style, so that each backend can translate them to the style of its target: types,
interfaces and enum variants are `PascalCase`; functions, variables, fields, constants and module
names are `snake_case`.

Wrong:

```wolf wrong
module main

functions {
    fn PrintAll(items: List<Int>) {
        print(items.len().to_string())
    }

    fn main() {
        PrintAll([1])
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn print_all(items: List<Int>) {
        print(items.len().to_string())
    }

    fn main() {
        print_all([1])
    }
}
```
