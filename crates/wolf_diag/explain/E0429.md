# E0429: type or module used as a value

A type or a module name stands where a value is expected. A type is not a value: build one with a
struct literal or a function. A module is used through its declarations: `module.name`.

Wrong:

```wolf wrong
module main

types {
    struct Point {
        x: Int
        y: Int
    }
}

main {
    let p = Point
    let _ = p
}
```

Fixed:

```wolf fixed
module main

types {
    struct Point {
        x: Int
        y: Int
    }
}

main {
    let p = Point { x: 0, y: 0 }
    let _ = p
}
```
