# E0429: type or module used as a value

A type or a module is used where a value is expected. Use a value of the type, or a function or
constant of the module.

Wrong:

```wolf
module main

functions {
    fn main() {
        let kind = Int
        print("hi")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let kind = 0
        print(kind.to_string())
    }
}
```
