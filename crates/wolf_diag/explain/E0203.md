# E0203: duplicate section

A section appears twice in one file. Each section is written at most once; merge the entries of the
second one into the first.

Wrong:

```wolf wrong
module main

config {
    a: Int = 1
}

config {
    b: Int = 2
}

functions {
    fn main() {
        print((a + b).to_string())
    }
}
```

Fixed:

```wolf fixed
module main

config {
    a: Int = 1
    b: Int = 2
}

functions {
    fn main() {
        print((a + b).to_string())
    }
}
```
