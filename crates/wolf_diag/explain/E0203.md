# E0203: duplicate section

A section appears twice in one file. Each section is written at most once; put all its entries
in one block.

Wrong:

```wolf
module main

functions {
    fn main() {
        print(twice(2).to_string())
    }
}

functions {
    fn twice(n: Int) -> Int { n * 2 }
}
```

Fixed:

```wolf
module main

functions {
    fn twice(n: Int) -> Int { n * 2 }

    fn main() {
        print(twice(2).to_string())
    }
}
```
