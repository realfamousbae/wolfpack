# E0202: section out of order

Sections have a fixed order: `imports`, `extern`, `config`, `types`, `interfaces`, `impl`,
`functions`, `tests`. The section named in the message comes after one that must follow it.

Wrong:

```wolf
module main

functions {
    fn main() {
        print(greeting)
    }
}

config {
    greeting: String = "hi"
}
```

Fixed:

```wolf
module main

config {
    greeting: String = "hi"
}

functions {
    fn main() {
        print(greeting)
    }
}
```
