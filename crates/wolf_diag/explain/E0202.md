# E0202: section out of order

Sections must appear in a fixed order: `imports`, `extern`, `config`, `types`, `interfaces`, `impl`,
`functions`, `tests`. Every section is optional, but the ones present keep this order, so a reader
always knows where to look. Move the section to its place.

Wrong:

```wolf wrong
module main

functions {
    fn main() {
        print(origin.to_string())
    }
}

config {
    origin: Int = 0
}
```

Fixed:

```wolf fixed
module main

config {
    origin: Int = 0
}

functions {
    fn main() {
        print(origin.to_string())
    }
}
```
