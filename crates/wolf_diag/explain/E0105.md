# E0105: invalid character escape

An escape `\xHH` or `\u{...}` does not name a valid character. `\xHH` takes two hex digits up to
`7F`, so it covers ASCII only. `\u{...}` takes one to six hex digits in braces, up to `10FFFF`, and
not a surrogate (`D800` to `DFFF`).

Wrong:

```wolf wrong
module main

config {
    letter: String = "\u41"
}

main {
    print(letter)
}
```

Fixed:

```wolf fixed
module main

config {
    letter: String = "\u{41}"
}

main {
    print(letter)
}
```
