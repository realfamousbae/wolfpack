# E0105: invalid character escape

A `\u{...}` escape does not name a valid Unicode scalar value: it is empty, has more than six hex
digits, is above `10FFFF`, or is a surrogate (`D800` to `DFFF`).

Wrong:

```wolf
module main

functions {
    fn main() {
        print("\u{110000}")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print("\u{1F600}")
    }
}
```
