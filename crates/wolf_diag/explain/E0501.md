# E0501: use of a moved value

Passing a value with `own`, returning it or putting it into another value moves it: the old name no
longer holds it, and any later use of that name is an error. Use the value before the move, or pass
a copy if both are needed: `take(u.copy())`. A fresh copy needs no `own` marker.

Wrong:

```wolf wrong
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

main {
    let u = User { name: "ann", tags: ["a"] }
    print(take(own u).to_string())
    print(u.name)
}

functions {
    fn take(own u: User) -> Int {
        u.tags.len()
    }
}
```

Fixed:

```wolf fixed
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

main {
    let u = User { name: "ann", tags: ["a"] }
    print(take(u.copy()).to_string())
    print(u.name)
}

functions {
    fn take(own u: User) -> Int {
        u.tags.len()
    }
}
```
