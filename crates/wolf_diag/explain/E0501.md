# E0501: use of moved value

Passing a value with `own`, returning it or putting it into another value moves it: the old name no
longer holds it, and any later use of that name is an error. Use the value before the move, or move
a copy if both are needed: `archive(user.copy())`.

Wrong:

```wolf wrong
module main

types {
    struct User {
        name: String
    }
}

functions {
    fn archive(own u: User) -> Int {
        u.name.len()
    }

    fn main() {
        let user = User { name: "ann" }
        print(archive(own user).to_string())
        print(user.name)
    }
}
```

Fixed:

```wolf fixed
module main

types {
    struct User {
        name: String
    }
}

functions {
    fn archive(own u: User) -> Int {
        u.name.len()
    }

    fn main() {
        let user = User { name: "ann" }
        print(archive(user.copy()).to_string())
        print(user.name)
    }
}
```
