# E0501: use of a moved value

A value is used after it was moved: passed to an `own` parameter, stored in another variable, or
returned. Moved values cannot be used again. Pass a copy (`x.copy()`), or move it last.

Wrong:

```wolf
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn make() -> User {
        User { name: "ann", tags: ["admin"] }
    }

    fn keep(own u: User) -> Int { u.tags.len() }

    fn main() {
        let u = make()
        print(keep(own u).to_string())
        print(u.name)
    }
}
```

Fixed:

```wolf
module main

types {
    struct User {
        name: String
        tags: List<String>
    }
}

functions {
    fn make() -> User {
        User { name: "ann", tags: ["admin"] }
    }

    fn keep(own u: User) -> Int { u.tags.len() }

    fn main() {
        let u = make()
        print(u.name)
        print(keep(own u).to_string())
    }
}
```
