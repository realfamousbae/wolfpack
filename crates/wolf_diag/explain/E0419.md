# E0419: cycle in type aliases or constants

Type aliases or constants refer to each other in a cycle, so none of them has a value. The
message shows the cycle.

Wrong:

```wolf
module main

config {
    width: Int = height * 2
    height: Int = width / 2
}

functions {
    fn main() {
        print((width + height).to_string())
    }
}
```

Fixed:

```wolf
module main

config {
    width: Int = height * 2
    height: Int = 10
}

functions {
    fn main() {
        print((width + height).to_string())
    }
}
```
