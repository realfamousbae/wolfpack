# E0419: cycle in type aliases or constants

A type alias is another name for a type, so it cannot contain itself; a recursive type is a struct
or an enum. Likewise a constant cannot depend on itself, directly or through other constants. The
message shows the cycle.

Wrong:

```wolf wrong
module main

config {
    width: Int = height * 2
    height: Int = width / 2
}

main {
    print((width + height).to_string())
}
```

Fixed:

```wolf fixed
module main

config {
    width: Int = height * 2
    height: Int = 10
}

main {
    print((width + height).to_string())
}
```
