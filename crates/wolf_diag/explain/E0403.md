# E0403: wrong number of type arguments

A generic type has the wrong number of type arguments: `List` takes one, `Map` and `Result` take
two, `Int` takes none.

Wrong:

```wolf
module main

functions {
    fn main() {
        let m: Map<String> = [:]
        print(m.len().to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        let m: Map<String, Int> = [:]
        print(m.len().to_string())
    }
}
```
