# E0403: wrong number of type arguments

A generic type is used with the wrong number of type arguments: `List` and `Option` take one, `Map`
and `Result` take two, and `Int` or a struct without parameters takes none. A generic type always
needs its arguments where it is written as a type.

Wrong:

```wolf wrong
module main

types {
    type Names = List<String, Int>
}

functions {
    fn main() {
        let n: Names = []
        print(n.len().to_string())
    }
}
```

Fixed:

```wolf fixed
module main

types {
    type Names = List<String>
}

functions {
    fn main() {
        let n: Names = []
        print(n.len().to_string())
    }
}
```
