# E0431: implementation that cannot be written

An `impl` block names something that cannot be implemented: a type that is not an interface,
`Equatable`, `Copyable` or `Hashable` (they are derived automatically), or an interface that the type
already implements.

Wrong:

```wolf
module main

types {
    struct Point {
        x: Int
    }
}

impl {
    Point: Equatable {
    }
}

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

types {
    struct Point {
        x: Int
    }
}

functions {
    fn main() {
        print((Point { x: 1 } == Point { x: 1 }).to_string())
    }
}
```
