# E0431: implementation that cannot be written

The header of an `impl` block names something that cannot be implemented: after `:` there must be an
interface, a type implements each interface once, and `Equatable`, `Copyable` and `Hashable` are
never implemented by hand: the first two are derived from the fields of a type, and `Hashable` is a
fixed set of types.

Wrong:

```wolf wrong
module main

types {
    struct Circle {
        r: Float
    }
}

impl {
    Circle: Equatable {
    }
}

main {
    let a = Circle { r: 1.0 }
    print((a == a).to_string())
}
```

Fixed:

```wolf fixed
module main

types {
    struct Circle {
        r: Float
    }
}

main {
    let a = Circle { r: 1.0 }
    print((a == a).to_string())
}
```
