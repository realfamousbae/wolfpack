# E0307: range outside `for` or index brackets

A range `a..b` or `a..=b` is not a value: it is written only after `for ... in` and inside index
brackets for slices, such as `items[1..3]`.

Wrong:

```wolf wrong
module main

main {
    let r = 0..3
    for i in r {
        print(i.to_string())
    }
}
```

Fixed:

```wolf fixed
module main

main {
    for i in 0..3 {
        print(i.to_string())
    }
}
```
