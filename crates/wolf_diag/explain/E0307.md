# E0307: range outside `for` or index brackets

A range `a..b` is written outside of a `for` loop and of index brackets. Ranges are not values;
use `list.range(a, b)` for a list of numbers.

Wrong:

```wolf
module main

functions {
    fn main() {
        let r = 1..4
        print("hi")
    }
}
```

Fixed:

```wolf
module main

imports {
    std.list
}

functions {
    fn main() {
        let r = list.range(1, 4)
        print(r.len().to_string())
    }
}
```
