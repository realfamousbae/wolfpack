# E0427: constant of a type that is not allowed

A constant has a type that constants cannot have. Constants are `Int`, `Float`, `Bool` or
`String`; build lists and maps in a function instead.

Wrong:

```wolf
module main

config {
    sizes: List<Int> = [1, 2]
}

functions {
    fn main() {
        print(sizes.len().to_string())
    }
}
```

Fixed:

```wolf
module main

functions {
    fn sizes() -> List<Int> { [1, 2] }

    fn main() {
        print(sizes().len().to_string())
    }
}
```
