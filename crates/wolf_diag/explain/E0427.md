# E0427: constant of a type that is not allowed

Constants are `Int`, `Float`, `Bool` or `String`, the types that `[config]` in `wolfpack.toml` can
override at build time. Other values, such as a list, are built in a function.

Wrong:

```wolf wrong
module main

config {
    sizes: List<Int> = [1, 2]
}

functions {
    fn main() {
        print(sizes.len().to_string())
    }
}
```

Fixed:

```wolf fixed
module main

functions {
    fn sizes() -> List<Int> {
        [1, 2]
    }

    fn main() {
        print(sizes().len().to_string())
    }
}
```
