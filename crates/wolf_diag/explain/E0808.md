# E0808: wolf could not be uninstalled

`wolf self uninstall` could not remove a file or a directory, or change the `PATH` of the user.
The message names the file and the reason. The steps go in an order that leaves a `wolf` that
runs when one fails: the `PATH` lines first, then the wolfpack home, and `wolf` itself last. A
`wolf` in a directory that only the administrator can change, such as `/usr/local/bin` of the
macOS package, is removed with the commands that the help shows.

Wrong:

```text
$ wolf self uninstall
Remove ~/.wolfpack too, with the tools of the targets (1.3 GB)? [y/N] n
kept ~/.wolfpack
error[E0808]: cannot remove wolf from /usr/local/bin: Permission denied (os error 13)
  = help: remove it with `sudo rm /usr/local/bin/wolf` and `sudo pkgutil --forget io.github.realfamousbae.wolfpack`
```

Fixed:

```text
$ sudo rm /usr/local/bin/wolf
$ sudo pkgutil --forget io.github.realfamousbae.wolfpack
Forgot package 'io.github.realfamousbae.wolfpack' on '/'.
```
