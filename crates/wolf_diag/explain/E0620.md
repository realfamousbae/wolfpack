# E0620: `pub` import outside `src/lib.wolf`

`pub` before an import re-exports the names, which is how a library builds its API. Only
`src/lib.wolf` can do that; in other modules imports are always private. Remove `pub`, or move the
re-export to `src/lib.wolf`.

Wrong:

```wolf wrong
module main

imports {
    pub std.list.{sum}
}

main {
    print(sum([1]).to_string())
}
```

Fixed:

```wolf fixed
module main

imports {
    std.list.{sum}
}

main {
    print(sum([1]).to_string())
}
```
