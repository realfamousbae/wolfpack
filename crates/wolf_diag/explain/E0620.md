# E0620: `pub` import outside `src/lib.wolf`

Only `src/lib.wolf` may re-export with `pub` imports; it defines the API of a library. Other modules
import without `pub`.

Wrong:

```wolf
module main

imports {
    pub std.list.{sum}
}

functions {
    fn main() {
        print(sum([1]).to_string())
    }
}
```

Fixed:

```wolf
module main

imports {
    std.list.{sum}
}

functions {
    fn main() {
        print(sum([1]).to_string())
    }
}
```
