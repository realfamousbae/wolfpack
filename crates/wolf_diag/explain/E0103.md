# E0103: unterminated string literal

A string literal has no closing `"` before the end of the line. Strings cannot span several lines;
write `\n` for a line break inside a string.

Wrong:

```wolf wrong
module main

config {
    greeting: String = "hello
}

main {
    print(greeting)
}
```

Fixed:

```wolf fixed
module main

config {
    greeting: String = "hello"
}

main {
    print(greeting)
}
```
