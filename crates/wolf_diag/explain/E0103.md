# E0103: unterminated string literal

A string literal is not closed with `"` before the end of the line. Strings cannot contain a raw
new line; write `\n` for a line break inside a string.

Wrong:

```wolf
module main

functions {
    fn main() {
        print("hello)
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print("hello")
    }
}
```
