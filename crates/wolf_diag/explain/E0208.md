# E0208: malformed `module` line

The `module` line is malformed: the path is missing, has empty parts, or is followed by
something else on the line.

Wrong:

```wolf
module main.

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print("hi")
    }
}
```
