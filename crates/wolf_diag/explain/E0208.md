# E0208: malformed `module` line

The `module` line holds only the keyword and a dotted path of lower-case names, such as
`module users.storage`. Something else follows the path on the same line, such as a `:` or a `{`.
Sections start on the following lines.

Wrong:

```wolf wrong
module main:

main {
    print("hi")
}
```

Fixed:

```wolf fixed
module main

main {
    print("hi")
}
```
