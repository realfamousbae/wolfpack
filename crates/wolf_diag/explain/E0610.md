# E0610: `module` line does not match the file path

The `module` line must match the path of the file: `src/users/model.wolf` declares
`module users.model`, and the entry file `src/main.wolf` declares `module main`. Change the line, or
move the file.

Wrong:

```wolf wrong
module app

main {
    print("hi")
}
```

Fixed:

```wolf fixed
module main

main {
    print("hi")
}
```
