# E0610: `module` line does not match the file path

The `module` line must match the path of the file: `src/users/storage.wolf` is
`module users.storage`, `src/main.wolf` is `module main`, `tests/math.wolf` is `module tests.math`.

Wrong:

```wolf
module app

functions {
    fn main() {
        print("hi")
    }
}
```

Fixed:

```wolf
module main

functions {
    fn main() {
        print("hi")
    }
}
```
