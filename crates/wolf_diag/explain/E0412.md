# E0412: alternatives bind different names or types

The alternatives of a pattern `A | B` share one arm body, so each of them must bind the same names
with the same types. A name bound in only one alternative would have no value in the body when the
other one matches. Split the arm in two.

Wrong:

```wolf wrong
module main

types {
    enum Value {
        Number(Int)
        Text(String)
        Nothing
    }
}

functions {
    fn show(v: Value) -> String {
        match v {
            Value.Number(n) | Value.Nothing => n.to_string()
            Value.Text(_) => "text"
        }
    }

    fn main() {
        print(show(Value.Nothing))
    }
}
```

Fixed:

```wolf fixed
module main

types {
    enum Value {
        Number(Int)
        Text(String)
        Nothing
    }
}

functions {
    fn show(v: Value) -> String {
        match v {
            Value.Number(n) => n.to_string()
            Value.Nothing => "nothing"
            Value.Text(_) => "text"
        }
    }

    fn main() {
        print(show(Value.Nothing))
    }
}
```
