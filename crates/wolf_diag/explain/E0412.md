# E0412: alternatives bind different names or types

The alternatives of a `|` pattern must bind the same names with the same types, so that the arm
body can use them whichever alternative matched.

Wrong:

```wolf
module main

types {
    enum Shape {
        Circle(Float)
        Square(Float)
    }
}

functions {
    fn size(s: Shape) -> Float {
        match s {
            Shape.Circle(r) | Shape.Square(_) => r
        }
    }

    fn main() {
        print(size(Shape.Circle(1.0)).to_string())
    }
}
```

Fixed:

```wolf
module main

types {
    enum Shape {
        Circle(Float)
        Square(Float)
    }
}

functions {
    fn size(s: Shape) -> Float {
        match s {
            Shape.Circle(r) | Shape.Square(r) => r
        }
    }

    fn main() {
        print(size(Shape.Circle(1.0)).to_string())
    }
}
```
